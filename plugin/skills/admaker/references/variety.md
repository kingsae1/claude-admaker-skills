# 변주 카드: 광고끼리 닮지 않게

변주 카드는 **모양**을, 아이디어 카드(`ideas.md`)는 **이야기**를 바꿉니다. 기록에는 변주 카드와 함께 고른 아이디어·예시·방향이 쌓이고, 다음 기획안 목록은 최근에 쓴 방향·아이디어·예시를 뒤로 미룹니다.

모션 방향(`motion-directions.md`)은 "어떤 형태로"를 정하고, 변주 카드는 **같은 방향 안에서 이번 광고만의 조합**을 정합니다. 방향 13개 × 축 8개의 칸을 섞기 때문에, 같은 방향을 골라도 광고마다 구도·글자 처리·그래픽·빛·카메라·전환·색·리듬이 달라집니다. 만든 광고의 카드를 기록해서 다음 광고는 최근에 쓴 칸을 피합니다.

## 축

| 축 | 정하는 것 | 칸 예 |
|---|---|---|
| 구도 | 화면 배치 | 왼쪽 정렬 그리드, 중앙 대칭, 분할 화면, 대각선, 프레임 속 프레임, 화면을 넘는 큰 글자, 콜라주, 무대 바닥 |
| 주인공 글자 처리 | 훅·주인공 문구가 들어오는 방식 | 글자 단위 3D, 마스크 상승, 슬램, 타자, 마키, 윤곽선 그리기, 도트 글자, 글리치 정착, 도장, 깊이에서 다가옴 |
| 그래픽 지원 층 | F1의 두 번째 층 | 도형 버스트, 선·링, 스티커, 하프톤, 픽셀 블록, HUD, Lottie, 마커, 정보 칩 그룹 |
| 빛·질감 층 | F1의 세 번째 층 | 빛 스윕, 글로우, RGB 분리, 스캔라인, 종이 결, 빛 망울, 도트 질감, 색 플래시 |
| 카메라 | F4의 장면 카메라 | 밀고 들어감, 빠지며 드러냄, 패닝, 회전 줌, Z축 돌리, 박마다 펀치, 칸 단위 스크롤 |
| 전환 계열 | 컷 2–3곳 중 주인공 전환 | 덮기, 플래시, 줌 스루, 카드, 잉크 번짐, 픽셀화, 글자 속으로, 매치 컷, 글리치 컷, 밀어내기 |
| 색 운용 | 브랜드 색을 쓰는 방식 | 2색 대비, 무채색 + 포인트, 어두운 바탕, 장면마다 교체, 듀오톤, 제한 팔레트 |
| 리듬 | 히트 간격 (F2) | 박마다, 2박마다, 엇박, 빌드업 → 드롭, 정지 → 폭발 |

요청 문장의 분위기 낱말도 봅니다. 키즈·귀여움이면 어두운 바탕·글리치·HUD를, 고급·프리미엄·차분·미니멀이면 도형 버스트·스티커·박마다 컷·글리치·회전 줌을, 신뢰(금융·병원·보험)면 글리치·스티커·회전 줌을, 감성·따뜻함이면 글리치·HUD·어두운 바탕·색 플래시를 뺍니다(`variety-core.mjs`의 `MOODS`). 칸마다 `only`(이 방향에서만, 예: 도트 글자는 픽셀 레트로만)와 `avoid`(이 방향에선 안 씀, 예: 픽셀 레트로에 3D·회전)가 있어서 방향과 어긋나는 조합은 나오지 않습니다. 목록 전체는 `templates/variety-core.mjs`의 `AXES`입니다.

## 쓰는 법

1. 기획안 목록(`gallery.mjs recommend`, MCP `get_gallery({ request })`)이 기획안마다 변주 카드를 한 장씩 붙여 줍니다. 기획안끼리도 칸이 겹치지 않게 뽑습니다.
2. 사용자가 기획안을 고르면 그 카드를 씬표 맨 위에 적고, 씬마다 어느 칸을 어디에 쓰는지 표시합니다. 카드는 출발점이라 브리프와 맞지 않는 칸 하나는 바꿔도 됩니다(바꾼 칸을 적음).
3. **사용자가 기획안을 고른 바로 그때** 카드를 기록합니다(내보내기까지 기다리지 않음: 사용자가 직접 다운로드하거나 중간에 멈춰도 기록이 남아야 다음 광고가 겹치지 않음). 칸을 바꿨으면 바꾼 카드로 다시 기록해도 됩니다(최근 것이 뒤에 쌓임).
   - 스킬: `node templates/variety.mjs record variety.json --title "광고 이름"` (`variety-cards.json`의 고른 카드)
   - MCP: `get_gallery({ recordVariety: <고른 기획안의 variety>, title })`
4. 같은 칸만 다시 뽑고 싶으면 `node templates/variety.mjs card <방향> --seed <카드의 seed>`.

규칙
- 최근 4편에 쓴 칸은 남는 칸이 있으면 피합니다. 최근 광고와 축 절반 이상이 같으면 다시 뽑습니다(`maxSimilarity` < 0.5).
- 카드의 칸도 aesthetic-rules(F1–F6, Q4 광효과 하나, Q11 소재 위)를 지킵니다. 칸이 규칙과 부딪히면 규칙이 먼저입니다.
- 자유롭게 생성도 카드를 뽑습니다(`free`, 방향 전용 칸 없이 공통 칸에서).
- 기록은 `~/.admaker/variety-history.json`(최근 50편) 한 파일을 스킬 CLI와 앱 MCP가 같이 씁니다.
- 참신안 기획안의 카드에는 `novel`(장르·페인·역할·톤·엔딩 칸 id)이 들어 있어 같이 기록되고, 다음 참신안은 최근 6편의 칸을 피합니다(`novel-concepts.md` §3).

## 기법 연결 검사

엔진에 기능이 생겼는데 메뉴(방향·샷 카드·기법 메뉴·변주 칸)에 없으면 기획안에 나오지 않습니다. `node templates/coverage.mjs`가 기법 목록과 엔진 필터·모션 타입·`am-*` 전환을 메뉴 파일과 대조해, 어디에도 안 걸린 것을 알려 줍니다. 엔진 기능을 스킬에 추가하면 이 검사를 통과할 때까지 방향·샷 카드·`techniques.md`·`variety-core.mjs`에 연결합니다.
