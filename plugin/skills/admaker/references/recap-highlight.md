# 줄거리 요약(리캡) 하이라이트

긴 영상(영화·드라마·웹드라마 회차, 자체 제작 시리즈, 다큐, 행사·브이로그 원본)을 **차분한 해설 내레이션 + 빠른 장면 컷**으로 줄여 이야기 한 편처럼 보여 주는 형식입니다. 유튜브의 영화·드라마 요약 채널들이 널리 쓰는 문법을 일반화한 프리셋이며, 특정 채널의 대본·말투·브랜딩을 흉내 내지 않습니다. 대본은 매번 새로 씁니다.

광고 기본값(화려하게, 박마다 히트, fade 금지, 모션 전용 씬)은 이 형식에서 **뒤로 물립니다.** 주인공은 원본 장면과 내레이션이고, 모션그래픽은 이해를 돕는 정보(장 제목, 인물 이름표, 시간 점프)만 얹습니다.

**핵심은 스토리가 먼저라는 것입니다.** 원본을 앞에서부터 잘라 붙이지 않습니다. 대사로 이야기를 파악하고, 장면을 나눈 뒤, 하이라이트 스토리를 새로 쓰고, 그 스토리에 맞는 장면을 원본 어디에서든 골라 스토리 순서로 놓습니다.

```
대사 뽑기 → 이야기 파악 → 장면 나누기 → 하이라이트 스토리 쓰기 → 스토리 순서로 장면 배치
  → 내레이션·자막·배우 대사 강조·효과음·(필요하면) 모션그래픽·전환
```

## 0. 시작 전 확인

| 항목 | 기준 |
|---|---|
| 원본 권리 | 사용자가 만든 영상이거나 쓸 권리가 있는 영상인지 한 번 묻습니다. 남의 영화·드라마면 저작권·플랫폼 정책 위험을 한 줄로 알리고, 결정은 사용자에게 맡깁니다. 원본 장면을 길게 그대로 잇지 않고(한 컷 6초 이하), 해설이 영상 시간의 대부분을 덮게 짭니다. |
| 스포일러 | 결말까지 말할지(전체 요약) 반전 직전에서 끊을지(티저형)를 고릅니다. 기본은 전체 요약이고, 첫 화면 자막이나 설명에 "결말 포함"을 적습니다. |
| 길이·규격 | 쇼츠 9:16 60초 / 90초, 가로 16:9 3분 / 5–10분. 쇼츠는 인물 얼굴이 화면 가운데 오게 `crop_clip`·focus로 다시 잡습니다. |
| 원본 자료 | 자막 파일(SRT·VTT·SMI)·줄거리·회차 정보가 있으면 받습니다. 자막 파일이 있으면 그걸 쓰고(가장 정확, 크레딧 없음), 없으면 음성 인식으로 대사를 뽑습니다(§1). 인물 이름은 대사·사용자 자료에 나온 것만 씁니다. |

## 1. 대사 뽑기 → 이야기 파악 → 장면 나누기

1. **원본 넣기**: `upload_media`로 올리고 `add_media_to_timeline`으로 넣습니다. 이 클립이 원본 클립(`clipId`)입니다.
2. **대사 뽑기**: `transcribe_clip { clipId }`. 자막 파일이 있으면 `subtitleText`에 내용을 넣습니다. 없으면 원본 소리를 음성 인식합니다(몇 분, 크레딧이 들 수 있어 먼저 알림). 결과는 `[{ index, fromSec, toSec, text }]`(원본 초)입니다. 긴 원본은 `fromSec`·`toSec`로 나눠 부르고 `nextOffset`으로 이어 받습니다.
3. **이야기 파악**: 대사 전체를 읽고 다섯 줄로 정리합니다. `주인공과 처지 · 바라는 것 · 일을 꼬는 사건 · 반전 · 결말`. 등장인물 표(이름이나 별명, 역할, 처음 나오는 원본 초)와 **결정적 대사 후보**(이야기를 뒤집거나 인물을 한 줄로 보여 주는 대사 5–10개, 원본 초와 함께)를 같이 적습니다.
4. **장면 나누기**: `detect_scenes { clipId }` → `[{ index, fromSec, toSec, midSec }]`. 너무 잘게 나뉘면 `threshold`를 올리거나 `minShotSec`를 늘립니다.
5. **장면 보기**: `view_shot_sheet { clipId, items: [{ atSec: midSec, label: "번호 · 시각" }] }`로 36칸씩 봅니다. 대사 구간과 장면 구간을 겹쳐 장면 목록을 만듭니다.
6. 장면 목록 칸: `장면 번호 · 원본 초 · 인물 · 무엇이 일어남 · 그 구간 대사 · 감정 세기(1–5) · 쓸 곳(훅/설정/사건/고조/반전/결말) · 배우 대사 강조 여부`.

## 2. 이야기 골격

**하이라이트 스토리를 먼저 씁니다.** 1번에서 파악한 이야기로 아래 골격을 채운 다음, 골격의 줄마다 그 내용을 보여 줄 장면을 장면 목록에서 고릅니다. 장면은 원본 순서와 상관없이 고릅니다. 훅에 결말 직전 장면, 설정에 뒤쪽 회상 장면, 고조에 여러 시점의 장면을 섞어 써도 됩니다. 단, 보는 사람이 시간 순서를 헷갈리면 안 되므로 시간이 거꾸로 가는 곳(훅의 플래시포워드, 회상)에는 내레이션이나 "몇 년 전" 자막으로 알려 줍니다. 비율은 결과물 길이에 대한 대략값입니다.

| 단계 | 비율 | 60초 쇼츠 | 하는 일 |
|---|---|---|---|
| 훅 | 5–8% | 0–4초 | 가장 센 장면 1–2컷 + 질문 한 줄("이 남자는 왜 자기 집에 불을 질렀을까?") |
| 설정 | 15% | 4–13초 | 주인공·처지·바라는 것을 2–3문장으로. 인물은 처음 나올 때 이름표 |
| 사건 | 15% | 13–22초 | 평범함이 깨지는 순간. "그런데 어느 날" |
| 고조 | 30% | 22–40초 | 일이 꼬이고 커짐. 문장마다 컷, 템포가 가장 빠른 구간 |
| 반전 | 15% | 40–49초 | 아껴 둔 센 장면. 직전에 0.5–1초 침묵이나 원본 소리 |
| 결말 | 10% | 49–56초 | 어떻게 끝났는지 담백하게 |
| 마무리 한 줄 | 5% | 56–60초 | 여운·평 한 문장. 구독·다음 편 유도는 사용자가 원할 때만 |

3분 이상이면 고조를 2–3마디로 나누고, 마디 끝마다 작은 클리프행어("하지만 그건 시작에 불과했다")를 둡니다.

## 3. 내레이션 대본

말투는 `narration.md` §2의 **신뢰·다큐 톤**에서 출발합니다. 낮고 고른 목소리, 빠르지만 서두르지 않는 속도, 감정은 문장이 아니라 장면이 맡습니다.

- **해설체 현재형**: "~한다", "~하는데", "~하고 만다". 존댓말 광고체("~하세요")는 쓰지 않습니다.
- **3인칭, 역할 이름**: 처음엔 "평범한 회사원 민수"처럼 역할+이름, 그다음엔 짧게. 등장인물이 많으면 이름 대신 별명("안경 형사")으로 구분하고 이름표 자막을 붙입니다.
- **한 문장 = 한 컷**: 문장은 15–35자. 긴 사건은 문장을 잘라 컷을 늘립니다.
- **이음말로 리듬**: "그런데", "하지만", "그렇게", "결국", "바로 그때". 같은 이음말을 연달아 두 번 쓰지 않습니다.
- **마디 끝 질문·여운**: "과연 그는 무사히 돌아갈 수 있을까." 한 편에 3–4번까지.
- **담백한 위트**: 상황을 한 박자 비튼 한 줄을 60초에 1번, 3분에 2–3번. 조롱·비하는 쓰지 않습니다.
- **분량**: 태그·공백 뺀 글자로 1초에 약 5자(60초 270–300자). 광고보다 조금 빠르고 쉼이 짧습니다(줄 사이 0.15–0.35초, 반전 앞만 0.6–1초).
- **원본 대사 인용**: 대본에는 `transcribe_clip` 결과나 사용자 자료에 있는 대사만 따옴표로 짧게 씁니다. 지어낸 대사를 원작 대사처럼 쓰지 않습니다.
- TTS 태그: 기본 `[Quiet, measured narration]`, 반전 앞 `[short pause]`, 위트 줄은 목록에 건조한 말투 태그가 있을 때만 씁니다. 모두 지금 엔진 목록에서만 고릅니다(`list_narration_tags` → `check_narration_tags`). 줄마다 같은 목소리·같은 스타일을 유지합니다.

연출표 칸은 `narration.md` §1과 같고, **장면 번호·원본 구간**(장면 목록)과 **배우 대사 강조**(없음 / 대사 원본 초·문장) 두 칸을 더합니다.

## 4. 컷 편집

| 규칙 | 값 |
|---|---|
| 컷 길이 | 1.5–4초. 고조 구간 1.5–2.5초, 설정·결말 3–4초. 한 컷 6초 넘기지 않음 |
| 말과 화면 | 문장이 말하는 대상이 그 순간 화면에 있음("민수는 편지를 숨긴다" → 편지 숨기는 손). 안 맞는 컷을 채우려고 아무 장면이나 넣지 않음 |
| 컷 경계 | 문장 끝(또는 큐 단어)에 맞춤. 다음 문장 첫 음절보다 0.1–0.2초 먼저 화면이 바뀌어도 됨 |
| 장면 순서 | 원본 순서가 아니라 하이라이트 스토리 순서(§2). 같은 장면을 두 번 쓰지 않음. 시간이 거꾸로 가는 곳은 내레이션·자막으로 알림 |
| 원본 소리 | 평소에는 낮게 깔기(0.1–0.2). 결정적 대사는 §4.1 배우 대사 강조로 살림 |
| 전환 | 하드컷이 기본. 단계(설정→사건 등)가 바뀌는 곳에만 짧은 dip-to-black 0.2–0.3초나 `am-*` 전환 하나. 시간 점프는 검은 화면 + "3년 후" 자막 0.8초 |
| 속도 | 지루한 이동 장면은 `update_clip { playbackRate: 1.5–2 }`, 반전 순간은 0.5–0.7 슬로 1회 |
| 원본 잘라 쓰기 | `trim`(원본 구간, μs)과 `display`(타임라인 구간)를 씀. `trim.to − trim.from = (display.to − display.from) × playbackRate` |

### 4.1 배우 대사 강조

이야기를 뒤집거나 인물을 한 줄로 보여 주는 대사는 내레이션 대신 **배우가 직접 말하게** 합니다. 60초에 1–2번, 3분에 4–6번까지. 1번에서 적은 결정적 대사 후보에서 고릅니다.

- 대사 구간은 내레이션을 비우고(앞 문장은 0.3초 전에 끝냄), 원본 소리를 1로 올리고, BGM을 더 낮춥니다.
- 화면에 대사 자막을 내레이션 자막과 다르게 띄웁니다(따옴표, 노랑 계열, 굵게, 내레이션 자막보다 조금 위).
- 대사 동안 살짝 줌인(1.0 → 1.08)해 얼굴에 시선을 모읍니다. 대사 앞 0.5초에 짧은 저음 히트나 무음을 둬도 됩니다.
- 대사 바로 뒤 내레이션은 그 대사를 받아서 시작합니다("그 한마디에 모든 게 무너진다").
- MCP: `place_story_shots`의 그 장면에 `keyLine { from, to, text }`(원본 초, `transcribe_clip` 문장 그대로)을 주면 볼륨 곡선·대사 자막·줌인을 한 번에 넣고, 결과 `keyLines`(타임라인 초)에 내레이션을 넣지 않을 구간을 돌려줍니다.

화면 위 모션그래픽은 세 종류만 씁니다. 모두 소재를 덮지 않게 작게, 1초 안에 들어오고 나갑니다.

- **인물 이름표**: 처음 나올 때 한 번, 얼굴 옆 하단. 이름 + 역할 한 줄.
- **장 제목·시간 점프**: "그날 밤", "3년 후". 화면 가운데 큰 글자는 이것만. 길이가 다른 문구는 `style.autoFit { mode: 'shrink', maxLines: 1 }`로 상자에 맞춥니다.
- **정보 카드**: 관계도·장소 이름이 필요할 때만 2–3초.

## 5. 자막

| 자막 | 위치·크기 | 스타일 |
|---|---|---|
| 내레이션 | 하단 중앙, 세이프존 안. 9:16 한 줄 14–18자 두 줄까지, 16:9 한 줄 20–28자 | 흰 글자 + 얇은 외곽선이나 반투명 줄 배경. 굵은 고딕 |
| 강조 단어 | 내레이션 자막 안 | Caption `style.wordAnimation { type: 'highlight', color, scale: 1.0–1.05, upcomingOpacity: 0.9–1 }`(앱 자막 프리셋 "단어 강조"). 문장마다 핵심어 0–1개에만 강조색, 모든 단어가 튀지 않게 transition 0.08초 이상 |
| 배우 대사 | 내레이션 자막보다 조금 위 | 따옴표 + 노랑 계열 + 굵게, 검은 외곽선. 배우 대사 강조(§4.1) 구간에만 |

자막에는 TTS 태그를 넣지 않고 숫자·이름은 화면 문구 칸 그대로 씁니다. 단어 시간이 없으면 단어 강조는 일반 자막으로 그려집니다.

## 6. 소리

| 층 | 기준 |
|---|---|
| 내레이션 | 0dB 기준 트랙. 줄마다 클립 하나 |
| 원본 소리 | 기본 0.1–0.2(−20dB 안팎)로 깔기(현장감), 배우 대사 강조 구간만 1. 클립 `volume`에 `[[초, 값], ...]` 곡선으로 올렸다 내림(`place_story_shots` `keyLine`이 자동으로 넣음) |
| BGM | 장르에 맞춘 낮은 배경 음악(스릴러 = 낮은 드론·펄스, 코미디 = 가벼운 피치카토, 드라마 = 피아노·현). 내레이션 아래로 덕킹 `duck { by: [내레이션 트랙], amount: −12, attack: 0.08, release: 0.35 }`(앱 오디오 속성 "음성 나올 때 낮추기") |
| 반전 | 직전 0.5–1초 BGM을 끊거나 크게 낮추고, 반전 장면과 함께 다시 올림 |
| 효과음 | 시간 점프 휘익·장 제목 저음 히트 정도. 원본 소리와 겹치지 않게 최소 |

## 7. 제목·썸네일

- **제목**: `[인물·처지] + [이상한 사건이나 반전 암시]`. 예: "평생 집 밖을 안 나간 남자가 문을 연 날". 결과물에 없는 내용을 약속하지 않습니다.
- **썸네일**: 감정 세기 5인 프레임 하나(인물 얼굴이 크게) + 큰 글자 두 줄(8–12자씩, 질문이나 반전 암시). 원작 포스터·로고를 그대로 쓰지 않습니다.
- 첫 화면(0초)이 썸네일 역할도 하므로 훅 첫 컷은 얼굴이나 사건이 바로 보이는 프레임으로 고릅니다.

## 8. MCP 진행 순서

1. 0번 확인(권리·스포일러·길이·규격·자료) → `ask_user_choice`로 길이·규격과 티저형/전체 요약을 한 번에 묻습니다.
2. 원본 올리기 → `transcribe_clip`(자막 파일 있으면 `subtitleText`) → 이야기 다섯 줄·인물 표·결정적 대사 후보.
3. `detect_scenes` → `view_shot_sheet`로 장면 목록(§1).
4. 하이라이트 스토리(§2 골격)와 연출표(§3, 줄마다 쓸 장면 번호·배우 대사 강조 여부)를 사용자에게 보여 주고 확인.
5. `ai.voice.generate`로 줄마다 내레이션(크레딧 확인 먼저) → 실제 줄 길이로 장면 길이 확정.
6. `place_story_shots { clipId, shots: [스토리 순서의 { from, to, label, keyLine? }] }`로 한 번에 배치(먼저 `dryRun: true`로 길이 확인). 원본 통째 클립은 소리가 꺼지니, 필요 없으면 `removeSource: true`. 9:16이면 `crop_clip`·focus로 얼굴 맞춤.
7. 내레이션 클립을 `keyLines` 구간을 피해 놓음 → 자막(내레이션 + 단어 강조) → 이름표·장 제목.
8. BGM(`ai.bgm.generate`, 장르별 영문 프롬프트) + 덕킹 + 효과음(시간 점프, 대사 강조 앞 히트) → 장 경계에만 전환.
9. 검수(9번) → 사용자가 Studio에서 미리보고 내보냄. 썸네일 프레임 후보 2–3개와 제목 후보 3개를 같이 줍니다.

## 9. 검수 체크리스트

- [ ] 첫 4초 안에 가장 센 장면과 질문이 있다.
- [ ] 장면이 원본 순서가 아니라 하이라이트 스토리 순서로 놓였고, 시간이 거꾸로 가는 곳은 알려 준다.
- [ ] 내레이션이 결과물 시간의 75–90%를 덮고, 배우 대사 강조 구간은 합쳐 10% 이하이며 그 구간에 내레이션이 겹치지 않는다.
- [ ] 한 컷이 6초를 넘지 않고, 문장이 말하는 대상과 화면이 맞는다.
- [ ] 모든 인물이 처음 나올 때 누구인지 알 수 있다(이름표나 문장).
- [ ] 대사 인용·이름·사실은 사용자 자료에 있는 것만 썼다.
- [ ] 자막이 세이프존 안이고, 강조색은 문장당 한 단어 이하.
- [ ] BGM이 내레이션을 가리지 않는다(덕킹 확인), 반전 앞 쉼이 있다.
- [ ] 결말 포함 여부가 사용자 선택대로다.
