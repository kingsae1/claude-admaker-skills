# 내레이션 연출과 오디오 태그

admaker의 내레이션(TTS)은 ElevenLabs v3/v4 모델로 만듭니다. 좋은 광고 내레이션은 TTS 품질보다 **연기 지시**에서 갈립니다. 같은 문장도 어디서 숨을 쉬고, 어느 단어를 밀고, 어느 컷에 맞춰 떨어지느냐에 따라 전혀 다르게 들립니다. 그래서 내레이션은 "대본 쓰기 → 연출표 → 생성 → 싱크·검수" 순서로, 성우 디렉터처럼 만듭니다.

이 모델은 대본 안의 **대괄호 영문 태그**(`[excited]`, `[short pause]`)를 읽지 않고, 감정·말투·쉼·호흡 지시로 씁니다. 목록에 없는 태그를 지어내면 그대로 읽힐 수 있습니다.

MCP에서는 `ai.voice.generate { text, voiceId, startSec }`의 `text`에 태그를 넣습니다. 앱(Planner·Quick·Studio)의 입력창에서는 `[`를 치면 같은 목록이 뜹니다. 한국어 화면에서는 `[신남]`처럼 한글 이름으로 보이지만, 실제로 API에 들어가는 값은 영문 태그입니다.

`ai.voice.generate`에는 속도·안정성 값을 넘길 수 없습니다(서버 고정). 속도·강약·쉼은 모두 **문장 구성, 문장부호, 태그, 클립 배치**로 만듭니다.

## 1. 연출표 먼저 만들기

씬표를 만든 뒤, 내레이션 문장마다 아래 칸을 채운 연출표를 만듭니다. 사용자에게 씬표와 함께 보여 주고, 생성은 연출표대로 합니다.

| 칸 | 뜻 | 쓰는 법 |
|---|---|---|
| 화면 문구 | 자막·모션그래픽에 보일 글 | 숫자·기호 그대로(`9,900원`, `50%`, `1+1`) |
| 읽을 문장 | TTS `text`에 넣을 글 | 소리 나는 대로 풀어 씀(§3) + 태그 0~2개 |
| 감정·말투 | 이 줄의 연기 | §6·§7의 태그로 옮김(`[curious]`, `[Quiet, measured narration]`) |
| 강조 단어 | 꼭 들려야 할 1단어 | 문장 끝 가까이 두고, 바로 앞에 쉼표나 `[short pause]` |
| 큐 단어·큐 시각 | 컷·비트·피크에 떨어질 단어와 그 초 | `audio.analyzeBeats`의 suggestedCuts·peaks에서 고름 |
| 뒤 쉼 | 다음 줄까지 비울 시간 | 0.2~0.8초. 클립 사이 간격으로 만듦(§4) |

예:

| 씬 | 화면 문구 | 읽을 문장 | 강조 | 큐 |
|---|---|---|---|---|
| 1 훅 0~3초 | 아직도 줄 서세요? | `[curious] 아직도, 줄 서서 드세요?` | 줄 | 2.0초 컷에 "드세요" |
| 2 혜택 3~8초 | 오늘만 50% | `[excited] 오늘 단 하루, [short pause] 전 메뉴 오십 퍼센트!` | 오십 퍼센트 | 5.5초 피크 |
| 3 CTA 8~10초 | 지금 주문 | `[Gradually building energy] 지금 바로 주문하세요.` | 지금 | 엔드카드 등장 |

## 2. 스타일 정하기

브리프의 톤으로 광고 전체의 내레이션 스타일을 하나 정하고, 줄마다 그 안에서 변화를 줍니다. 스타일을 줄마다 바꾸면 한 사람이 읽는 느낌이 깨집니다.

| 스타일 | 언제 | 연기 | 태그 |
|---|---|---|---|
| 광고 기본 | 대부분의 상품·매장·이벤트 | 또렷하게, 키워드를 밀고, 끝으로 갈수록 에너지 | 훅 `[curious]`, 혜택 `[excited]`, CTA `[Gradually building energy]` |
| 신뢰·다큐 톤 | 병원·금융·브랜드 필름·공익 | 낮고 안정적, 짧은 침묵과 여운 | `[Quiet, measured narration]`, `[calm]`, `[softly]`, 줄 사이 0.5~0.8초 |
| 시네마틱 | 티저·런칭·감성 브랜드 | 속삭임에서 고조로, 극적인 호흡 | `[whispers]` → `[inhales deeply]` → `[Gradually building energy]` |
| 경쾌 | 분식·디저트·키즈·팝업 | 빠르고 가볍게, 의성어 살림 | `[Quick, light, playful pace]`, `[chuckles]` |

목소리는 스타일에 맞게 `list_voices`에서 고릅니다. 차분한 목소리에 `[shouts]`, 들뜬 목소리에 `[whispers]`처럼 성격과 반대인 태그는 잘 안 먹습니다.

## 3. 읽을 문장 쓰기 (화면 문구와 분리)

화면 문구와 읽을 문장은 따로 씁니다. 화면은 짧고 숫자·기호가 잘 읽히게, 읽을 문장은 **소리 나는 대로** 씁니다. 서버가 TTS 전에 기호를 영어로 바꾸기 때문에, 기호를 그대로 두면 한국어 문장 중간에 영어가 끼어 읽힙니다.

| 화면 문구 | 그대로 넣으면 | 읽을 문장 |
|---|---|---|
| `50%` | "50 percent" | `오십 퍼센트` |
| `1+1` | 기호가 흔들림 | `원 플러스 원` |
| `A&B` | "A and B" | `에이 앤 비` (브랜드 공식 읽기) |
| `24/7`, `10/31` | "slash" | `연중무휴`, `시월 삼십일일` |
| `#신상` | "number 신상" | `신상` |
| `$`, `@` | "dollars", "at" | `달러`, `앳` 또는 빼기 |
| `9,900원` | 잘 읽지만 끊김이 어색할 때가 있음 | `구천구백 원` |
| `3개`, `2시` | "삼 개", "이 시"로 읽힐 수 있음 | `세 개`, `두 시` |
| `010-1234-5678` | 숫자 덩어리 | `공일공, 일이삼사, 오육칠팔` |
| `NEW`, `SALE` | 철자로 읽을 수 있음 | `뉴`, `세일` |

더 지킬 것:

- **줄 맨 앞에 `1. ` `- ` `> `를 쓰지 않습니다.** 서버가 목록 기호로 보고 지웁니다. `**굵게**`, `` `코드` ``, `|표|`도 지워지니 마크다운을 쓰지 않습니다.
- **영어 브랜드·제품명은 한글 발음으로** 씁니다(`Admaker` → `애드메이커`). 브랜드가 정한 읽기가 있으면 그것을 따릅니다.
- **문장은 짧게, 한 줄에 메시지 하나.** 쉼표로 호흡 단위를 나누고, 한 호흡은 12자 안팎으로 둡니다. 문장이 길면 TTS가 중간 억양을 무너뜨립니다.
- **강조 단어는 문장 끝 가까이** 둡니다. 한국어는 마지막 어절에 힘이 실립니다. 대문자·별표 강조는 한국어에서 효과가 없습니다.
- **문장 끝은 마침표·물음표·느낌표로 닫습니다.** 물음표는 끝을 올리고, 느낌표는 에너지를 올립니다. 말줄임표(…)는 여운이 필요한 곳에만 씁니다.
- 어색한 번역투·AI 문체(“~할 수 있습니다”, “~를 경험하세요”의 반복)는 말로 하는 구어체로 다듬습니다. 카피 원칙은 `copy.md`.

## 4. 분량과 싱크

**분량.** 태그와 공백을 뺀 글자 수로 셉니다. 한 문장을 읽는 속도는 1초에 약 6~7자지만, 광고 전체에는 숨·침묵·엔드카드가 들어가니 **전체 분량은 1초에 약 4자**로 잡습니다.

| 광고 길이 | 내레이션 전체 분량 | 줄 수 |
|---|---|---|
| 6초 | 15~22자 | 1~2 |
| 15초 | 45~60자 | 2~4 |
| 30초 | 100~125자 | 4~7 |
| 60초 | 220~255자 | 8~14 |

씬 하나에는 `(씬 길이 − 0.5초) × 6자`를 넘지 않게 씁니다. 쉼 태그는 0.5~1.5초를 더합니다.

**한 줄 = 클립 하나.** 내레이션은 문장(줄) 단위로 따로 만듭니다. 한 번에 길게 만들면 씬에 맞출 수 없고, 한 줄만 고칠 때도 전체를 다시 사야 합니다. 고칠 때는 **바뀐 줄만** 다시 만들고(크레딧 다시 확인), 이전 클립은 지웁니다.

**큐에 맞춰 놓기.** 줄의 `startSec`는 기본으로 `씬 시작 + 첫 비트 조금 뒤(0.1~0.3초)`입니다. 큐 단어를 컷이나 피크에 떨어뜨려야 하면 `startSec = 큐 시각 − (큐 단어 앞 글자 수 ÷ 6.5)`로 잡고, 만든 뒤 실제 길이를 보고 0.1초 단위로 옮깁니다.

**쉼은 클립 간격으로.** 줄 사이 쉼(연출표의 "뒤 쉼")은 `[pause]` 태그보다 다음 클립의 `startSec`를 늦춰서 만듭니다. 쉼 길이를 정확히 맞출 수 있고 다시 만들 필요도 없습니다. 태그 쉼은 한 문장 안에서 끊을 때만 씁니다.

**길이 확인.** 만든 뒤 `get_editor_state`(또는 `get_timeline_items`)로 클립 길이를 봅니다. 씬 끝을 넘으면 문장을 줄여 다시 만들거나 이웃 씬과 합칩니다. 예상(글자 수 ÷ 6.5 + 쉼)보다 1.5배 이상 길면 태그·기호·영어를 소리 내어 읽었을 가능성이 크니 읽을 문장을 다시 봅니다.

**BGM 덕킹.** 내레이션이 있는 구간에서 BGM 볼륨을 약 0.3~0.4로 낮춥니다(`clip.setVolume`). 내레이션이 없는 훅·엔드카드 구간은 BGM을 다시 살립니다. 효과음은 내레이션 강조 단어와 겹치지 않게 놓습니다.

**자막·화면 문구.** 자막은 화면 문구 칸을 쓰고 태그를 넣지 않습니다(앱도 자막에서 태그를 지웁니다). 자막의 시작·끝은 그 줄 내레이션 클립의 시작·끝에 맞춥니다. 모션그래픽 문구와 내레이션이 같은 내용을 같은 때 말하게 맞춥니다.

## 5. 태그 규칙

1. **태그는 영문, 대괄호 안에, §7 목록에서만 고릅니다.** 한글 이름(`[신남]`)으로 써도 앱이 영문으로 바꿔 주지만, MCP에서는 영문으로 씁니다.
2. **문장당 0~2개만 넣습니다.** 태그를 늘린다고 연기가 좋아지지 않고, 오히려 발음이 흔들립니다. 감정 태그는 문장 맨 앞에, 반응·쉼 태그는 그 일이 일어나는 자리에 둡니다.
3. **쉼은 문장부호와 클립 간격이 먼저입니다.** 꼭 문장 안에서 끊어야 할 곳에만 `[short pause]`(약 0.5초)를 넣습니다. `[long pause]`는 광고 길이를 잡아먹으니 거의 쓰지 않습니다. SSML `<break>`는 지원하지 않습니다.
4. **광고에 맞지 않는 태그는 근거가 있을 때만 씁니다.** 슬픔·분노·울먹임은 공익·감성 광고 같은 분명한 이유가 있을 때만 씁니다. 총성·폭발 같은 효과음 태그는 목록에 없으니 쓰지 않습니다. 효과음이 필요하면 `ai.sfx.generate`로 따로 만듭니다.

## 6. 광고에서 자주 쓰는 태그 조합

| 자리 | 태그 | 예 |
|---|---|---|
| 훅 질문 | `[curious]` | `[curious] 아직도 줄 서서 드세요?` |
| 혜택·오픈·이벤트 | `[excited]` | `[excited] 오늘 단 하루, 전 메뉴 반값!` |
| 한정·비밀 | `[whispers]` | `[whispers] 단골만 아는 메뉴가 있어요.` |
| 가격 강조 직전 | `[short pause]` | `단돈 [short pause] 9,900원.` |
| 음식·향 | `[inhales deeply]`, `[gulps]`, `[sighs]` | `[inhales deeply] 이 냄새, 참을 수 있어요?` |
| 프리미엄·병원·금융 | `[Quiet, measured narration]` | `[Quiet, measured narration] 오래 머물수록 더 편안해집니다.` |
| 분식·디저트·팝 | `[Quick, light, playful pace]` | `[Quick, light, playful pace] 바삭, 쫀득, 달콤!` |
| CTA 앞 고조 | `[Gradually building energy]` | `[Gradually building energy] 지금 바로, 가까운 매장에서 만나요!` |
| 바·고깃집 무드 | `[low, gravelly voice]` | `[low, gravelly voice] 오늘 밤은 여기서.` |
| 웃음·여유 | `[chuckles]`, `[laughs]` | `[chuckles] 한 번 오면 또 오게 될걸요.` |

## 8. 자가검사

- 줄마다 화면 문구와 읽을 문장이 나뉘어 있고, 읽을 문장에 `% & / # @ $ +`·마크다운·줄 앞 목록 기호가 없나요?
- 숫자·영어·브랜드명이 소리 나는 대로 쓰여 있나요?
- 태그가 모두 §7 목록에 있고 영문이며, 문장마다 2개 이하인가요?
- 전체 분량이 광고 길이 × 4자 안팎이고, 씬마다 `(씬 길이 − 0.5) × 6자` 안에 들어가나요?
- 줄마다 클립이 따로 있고, 큐 단어가 정한 컷·피크에 떨어지나요?
- 내레이션 구간에서 BGM이 낮아져 있나요?
- 자막에 태그가 섞여 있지 않나요?
