# 영상 이펙트: 얼굴 추적 (3종)

얼굴·머리에 붙는 그래픽입니다. 앱에 얼굴 추적 도구가 아직 없어서 **위치를 손으로 줍니다**(근사). 카메라가 고정된 상반신 영상·사진이면 그럴듯하게 나옵니다. 카탈로그는 `video-effects.md`.

## 위치 주기

- 고정: `head = { x, y }`(머리 꼭대기 근처) 또는 `face = { x, y, w, h }`(얼굴 가운데와 크기), 캔버스 px.
- 움직임: `track = [[t, x, y], …]` — 0.5–1초 간격으로 스틸에서 잰 위치. 그 사이는 직선으로 이어집니다. 인물이 크게 움직이는 영상은 0.25초 간격, 그래도 어긋나면 이 효과 대신 화면 고정 오버레이(`video-effects-overlay.md`)를 씁니다.
- 재는 법: 앱이면 `timeline.seek` + `app_screenshot`, 스킬이면 `ffmpeg -ss <t> -i in.mp4 -frames:v 1 f.png` 후 이미지에서 픽셀 좌표를 읽습니다. 바닥 소재를 cover로 깔았으면 소재 좌표가 아니라 **캔버스 좌표**입니다.
- 샘플(`samples/video-effects` face)은 사진에 흔들림 keyframes를 주고 같은 값으로 track을 만들었습니다. 그래픽과 바닥을 같은 경로로 움직이면 완전히 붙습니다.

## 19. 머리 위 라벨 `headLabel`

"사장님 추천", "MD Pick", 인물 소개·직함. 머리 위 `gap`(150px)에 알약 라벨 + 꼬리선이 `easeOutBack`으로 튀어나와 track을 따라다니고 끝에 줄며 사라집니다.

| 값 | 기본 | 감각 |
|---|---|---|
| `label` | "사장님 추천" | 8자 이하 |
| `color` / `ink` | #FFE14D / #111 | 바닥이 노란 계열이면 바꿈 |
| `size` | 52 | 9:16에서 48–60 |

함정: 라벨·꼬리·글자는 같은 위치 정지점을 씁니다. 하나만 고치면 떨어져 보입니다.

## 20. 얼굴 스캔 `faceScan`

AI 피부 진단, 맞춤 추천, 테크. 얼굴 박스에 모서리 괄호(1.5배에서 조여짐) → 점·선 격자 → 위아래로 오가는 스캔 선(0.7초 주기) → 아래 "MATCH 98%"가 0에서 세어 올라갑니다.

- `face.w·h`는 얼굴보다 15% 크게. 너무 꽉 맞추면 괄호가 볼을 가립니다.
- 숫자·문구(`label`, `value`)는 근거 있는 값만(진단 결과를 지어내지 않음). 근거가 없으면 `label: "SCANNING"`, `value: 100`처럼 진행률로 씁니다.

## 21. 이모지 반응 `emojiReact`

라이브 방송 반응, "반응 폭발", 리뷰. 얼굴 옆 `anchor`에서 `every`(0.28초)마다 이모지가 튀어나와 `rise`(520px) 위로 흔들리며 떠오르고 사라집니다.

- 이모지는 SVG로 직접 그립니다(`fx.emojiSvg`: heart·laugh·fire·wow·thumbs·star). 시스템 이모지 글꼴에 기대지 않아 앱·하니스에서 같게 나옵니다.
- `anchor`는 얼굴 옆(입 높이, 얼굴 가장자리에서 80–120px). 얼굴 위에 두면 표정을 가립니다.
- 3초에 10개 안팎. 더 많으면 `every`를 0.2까지.

## MCP로 직접

세 효과 모두 Shape·Text·Image만 써서 `add_clip`으로 넣을 수 있습니다. 라벨 하나 정도는 `add_clip { type: 'Shape', shapeType: 'pill' }` + Text를 같은 animations로 넣고, 여러 개면 스킬에서 만들어 가져옵니다.
