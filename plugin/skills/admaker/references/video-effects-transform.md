# 영상 이펙트: 인물 변형 (11종)

인물(누끼) 자체를 바꾸는 효과입니다. 망점 인쇄·컬러 분리·잔상 트레일은 누끼 없이 화면 전체(영상 포함)에 걸리고, 나머지는 누끼 PNG가 필요합니다. 카탈로그는 `video-effects.md`.

공통

- `subject = { src, box }`. 네온 윤곽선·스티커 팝·지폐 초상은 누끼를 SVG 안에 넣어 필터를 거므로 **src가 data URL**이어야 합니다. 앱 URL이면 먼저 받아서 바꿉니다: `"data:image/png;base64," + Buffer.from(await (await fetch(url)).arrayBuffer()).toString("base64")`.
- 트랙 매트를 쓰는 효과(머리 쌓기·코드·아스키·프레임 탈출)는 매트 클립(누끼·도형)이 대상 클립 구간을 다 덮어야 합니다. 함수가 같은 구간으로 만들어 주니 잘라 쓸 때 둘을 같이 자릅니다.
- 이미 있는 클립을 고치는 함수(망점·컬러 분리, 전환·카메라의 임팩트·글리치·초점 이동)는 **함수를 부른 뒤에** 그 클립을 배열·프로젝트에 넣습니다. 먼저 복사해 넣으면 붙인 효과가 빠집니다.
- 클립 효과(dot·rgbSplit·adjustment)는 **한 클립에 한 시각 하나**만 걸립니다. 같은 클립에 망점과 컬러 분리를 동시에 걸지 않습니다.

## 8. 분신 줄세우기 `cloneLineup`

"모두가 쓰는", "N가지 버전". 같은 누끼가 양옆으로 `count`쌍 미끄러져 나옴(뒤로 갈수록 12%씩 작고 15%씩 옅게, `stagger` 0.12초). 본체가 맨 위.

- `spacing` 기본 화면 폭 20%. 4쌍이면 화면 밖으로 나가는 분신이 생기는데 의도된 것입니다.
- 분신마다 색을 바꾸려면(제품 색상 라인업) 반환된 분신 클립에 `effects: [{ key: "colorOverlayFilter", values: { color, alpha: 0.4 }, startTime: 0, duration }]`.

## 9. 머리 쌓기 `headStack`

코믹, "N배 즐거움". 누끼를 여러 장 복사해 **머리 원 모양 트랙 매트**로 머리만 남기고 위로 쌓습니다(`easeOutBounce`로 떨어짐, 좌우로 ±3° 기울기 번갈아).

- `head = { cx, cy, r }`은 캔버스 좌표의 머리 원. 스틸에서 잽니다(턱이 원 아래 끝, 머리카락이 위 끝).
- 쌓는 간격 = 머리 지름 × `squash`(0.92). 3–4개까지(화면 위로 넘침).
- 매트 원은 복사본과 같은 keyframes로 움직입니다. 하나만 고치면 머리가 잘립니다.

## 10. 코드 인간 `codeHuman`

테크·앱·AI. 본래 인물이 `swapAt`에서 0.4초 동안 어두워지고, 실루엣 안에서만 초록 고정폭 코드가 아래로 흐릅니다(Text에 `style.matte { clipId: 누끼, mode: "alpha" }`).

- 글꼴 Space Mono 700, `size` 34. 코드 문구는 `chars`로 바꿀 수 있습니다(브랜드 이름·제품 키워드를 섞으면 좋음).
- 확인: 실루엣 밖으로 글자가 새지 않는지, 머리 윤곽이 읽히는지(작은 글자가 머리 쪽에 충분히 있어야 함).

## 11. 아스키 인간 `asciiHuman`

레트로·해커 감성. 실루엣이 아스키 문자 격자로 바뀌고(누끼 alpha 매트), 그 위에 누끼를 multiply 0.55로 얹어 얼굴 명암을 살립니다. 문자는 0.25초마다 미세하게 깜빡입니다.

- 문자 밀도 `size` 30(1080 폭에서 60열). 작을수록 얼굴이 잘 보이고 무겁습니다.
- 진짜 밝기별 문자 고르기(밝은 곳 `.`, 어두운 곳 `@`)는 아닙니다. 그게 필요하면 누끼 이미지를 미리 아스키로 바꾼 PNG를 만들어 Image로 넣습니다.

## 12. 네온 윤곽선 `neonOutline`

밤·클럽·게임·에너지 음료. 인물이 0.3초에 어두워지고(brightness 0.35), 몸 둘레에 두 겹 네온(안쪽 분홍 8px + 바깥 하늘 24px 블러)이 형광등처럼 깜빡이며 켜진 뒤 0.5초마다 숨쉬듯 밝기가 흔들립니다.

- 윤곽선은 SVG `feMorphology dilate − 원본`(`fx.outlineSvg`)이라 누끼 가장자리를 정확히 따라갑니다.
- 배경은 어둡게. 밝은 배경에서는 네온이 안 삽니다.

## 13. 스티커 팝 `stickerPop`

귀여움·SNS·굿즈. 누끼에 흰 테두리(`border` 16px) + 아래 그림자를 붙여 스티커로 만들고, 0.2배에서 `easeOutBack`으로 튀어나와 −6°로 붙습니다.

- 같은 장면에 스티커 여러 장이면 각도를 ±4–10°로 다르게, 시작을 0.1초씩 엇갈리게.
- 테두리가 두꺼우면(24+) 손가락·머리카락 사이 틈이 메워져 실루엣이 뭉개집니다.

## 14. 망점 인쇄 `halftonePrint`

빈티지·인쇄물·잡지. 대상 클립에 `dotFilter`(scale 4, angle 5 — 앱 슬라이더 범위 scale 0.3–5, angle 0–10)를 걸고 종이색 + 잔점 SVG를 multiply로 얹습니다.

```js
const photo = fx.scene("photo", spec, 0, 3, full);
clips.push(photo, ...fx.halftonePrint({ target: photo, from: 0, to: 3 }));
```

- `grayscale: true`면 흑백 신문, 기본(false)은 컬러 망점.
- 영상에도 됩니다(클립 효과). 화면 전체를 망점으로 하려면 바닥 소재 클립에 겁니다.

## 15. 지폐 초상 `banknotePortrait`

"돈 버는", 금융·재테크·가성비. 지폐(종이색, 이중 테두리, 기요셰 물결 28줄, 액면가)를 SVG로 그리고 가운데 타원에 누끼를 **초록 4단 판화 색**(feColorMatrix 흑백 → 단계 색표) + 가는 가로 줄무늬로 넣어, 3D로 뒤집히며 날아옵니다.

- 근사입니다. 진짜 동판화 결(곡선 해칭)은 `ai.image.edit { clipRef: 인물 사진, prompt: "engraved banknote portrait, intaglio line hatching, green ink" }` 정지 컷이 낫고(크레딧 확인), 그 결과를 `subject.src`로 넣으면 지폐 틀은 그대로 씁니다.
- `value`·`title`은 SVG `<text>`라 시스템 글꼴(serif)로 그려집니다. 한글 문구는 Text 클립으로 따로 얹습니다.
- 실존 화폐 도안을 흉내 내지 않습니다(가상의 지폐).

## 16. 컬러 분리 `colorSplit`

임팩트, 음악 비트, 패션. 대상 클립에 `rgbSplitFilter`를 짧은 구간 `steps`개(기본 8)로 이어 붙여, R·B가 좌우로 `offset`(28px)까지 벌어졌다 합쳐집니다(values가 고정이라 구간을 나눠 움직임을 냄).

```js
const shot = fx.scene("shot", { type: "Video", src }, 0, 3, full);
fx.colorSplit({ target: shot, at: 0.3, dur: 1.2 });
clips.push(shot);
```

- 비트에 맞추려면 `at`을 피크에, `dur` 0.4–1.2초. 광고 하나에 2–3번까지.

## 17. 잔상 트레일 `echoTrail`

속도감·댄스·스포츠·제품 회전. 원본을 깔고, 같은 영상을 `lag`(0.12초)씩 앞 시점에서 시작하는 복사본 `count`개(불투명도 0.6ⁿ, screen 혼합)를 그 **위에** 얹습니다(꽉 찬 영상이라 아래에 두면 가려짐). 누끼가 필요 없습니다.

- 영상 스펙(`type: "Video"`)이면 `trimFrom`을 당겨 과거 프레임을 보여 줍니다. 원본 `trimFrom`이 `lag × count`보다 작으면 앞 복사본은 0초에서 멈춰 있으니, 원본 시작을 그만큼 늦춥니다.
- 이미지 + keyframes로 움직이는 클립은 `spec.animations`를 넘기면 복사본 시작을 늦춰 같은 움직임을 뒤따르게 합니다.
- 어두운 배경 위 밝은 피사체에서 가장 잘 보입니다(screen은 밝은 쪽만 남김). 밝은 배경이면 `blend: "multiply"`.
- 배경이 거의 안 움직이는 영상(고정 카메라)에서 잘 보입니다. 카메라가 움직이면 화면 전체가 번집니다.
- `tint`(예 `0xff2bd6`)를 주면 잔상에 색을 입힙니다.

## 18. 프레임 탈출 `frameEscape`

"화면 밖으로", 3D 느낌, 시선 끌기. 벽 위 액자 안에서만 보이던 사진(액자 안쪽 사각 트랙 매트)에서 `at`(0.9초)에 누끼가 매트 없이 위로 1.22배·−150px 튀어나와 액자 테두리 밖으로 머리·어깨가 나옵니다.

- `spec` = 원본 사진, `subject` = 같은 사진의 누끼, 둘 다 같은 박스.
- `frame`은 인물 머리가 액자 위 테두리 근처에 오게 잡습니다(그래야 튀어나올 때 테두리를 넘음).
- 확인: 탈출 후 스틸에서 머리가 테두리 위에 있고, 액자 안 배경은 그대로인지.

## MCP로 직접

- 망점·컬러 분리·잔상은 앱 클립에 `update_clip { patch: { … } }`로 효과를 붙이기보다, 이 함수로 만든 클립을 가져오는 쪽이 정확합니다(구간 나눈 효과 목록).
- 누끼는 `run_studio_tool { toolId: 'ai.image.removeBackground', params: { clipRef } }`(크레딧 확인 후). 결과 PNG URL을 data URL로 바꿔 네온·스티커·지폐에 씁니다.
