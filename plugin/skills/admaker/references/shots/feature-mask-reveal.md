슬롯: 상승부 (혜택 하나당 한 번)
에너지: 중고

엔진: Image `wipe` 또는 `angleWipe`, Text `line_rise`, Shape(강조 바) `centerExpand`

## 의도
혜택 하나를 화면 하나로. 마스크가 열리는 방향이 다음 장면으로 시선을 넘깁니다.

## 동작 핵심
- 이미지가 `wipe`로 0.45초에 열림. 방향은 이전 장면의 움직임을 이어받음
- 강조 바(Shape, 강조 색)가 `centerExpand`로 0.3초, 문구 아래 또는 뒤
- 문구 `line_rise` 줄 단위, 이미지가 70% 열렸을 때 시작
- 다음 혜택으로는 같은 방향 와이프로 덮어 넘김(전환 셰이더 대신 매체 안의 전환)

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 와이프 | 0.4–0.5초, `easeInOutQuart` | 0.3초보다 빠르면 깜빡임처럼 보임 |
| 문구 시작 | 와이프 진행 70% 지점 | 와이프 끝까지 기다리면 늘어짐 |
| 문구 홀드 | 한국어 (글자 수 ÷ 5 + 1.2)초 이상 | 혜택 문구는 끝까지 읽혀야 함 |
| 같은 카드 반복 | 혜택 2–3개까지, 방향·프리셋을 바꿔서 | 4번째부터 단조로움(R5) |

## 사운드
와이프에 짧은 whoosh, 강조 바에 작은 탭/스냅. 혜택이 바뀔 때마다 음색을 살짝 바꿉니다(샘플 2개 교대).

## 알려진 함정
- 와이프 방향을 매번 바꾸면 리듬이 끊김 → 한 섹션 안에서는 같은 방향
- 강조 바와 강조 단어를 둘 다 강조 색으로 → B2 위반, 하나만

## 참조 구현
```jsonc
// 이미지
{ "type": "wipe", "options": { "duration": 450000, "delay": 0, "easing": "easeInOutQuart" }, "params": { "direction": "left" } }
// 강조 바 Shape
{ "type": "centerExpand", "options": { "duration": 300000, "delay": 250000, "easing": "easeOutCubic" }, "params": { "axis": "x" } }
```
`direction`, `axis` 값의 정확한 이름은 엔진 버전의 타입 정의에서 확인합니다(engine-recipes §0).
