## 의도
"녹는다·흘러넘친다·뚝뚝 떨어진다"를 글자나 아이콘 자체로 보여 줍니다. 여름 세일(녹아내리는 가격), 소스·시럽·꿀·초콜릿·페인트·화장품 제형, 앱 아이콘이 흘러내리며 등장하는 런칭 훅에 어울립니다. 대상과 **같은 단색**이라 이음매가 안 보여 한 덩어리 액체로 읽힙니다.

## 동작 핵심
드립 하나 = 같은 색 도형 3–4개.
- **목**: 오목한 어깨로 대상 아랫변에서 녹아 나오고, 아래끝은 뾰족한 원뿔. 윗변은 대상 안으로 4px 겹칩니다.
- **줄기**: 폭 w 알약이 scaleY로 늘어남. 엔진 scale은 가운데 기준이라 윗끝 고정은 `y = -L/2·(1−scaleY)`.
- **방울**: 위가 좁은 눈물 모양. 폭이 줄기와 같은 지점(높이 45/140)을 줄기 끝에 맞추고 줄기와 **같은 이징**으로 따라가서 늘 끝에 붙어 있습니다.
- **끊김(`fall`)**: 끊기기 0.3초 전부터 줄기가 가늘어지고(scaleX 0.55) 목이 좁아집니다. 끊기면 남은 목의 뾰족한 끝이 튕겨 올라가 출렁이다 작은 혹으로 남고, 떨어지는 줄기는 둥근 윗끝이 방울 쪽으로 0.2초 만에 빨려 들어가며, 방울은 그걸 삼키며 출렁이면서 떨어집니다. 끊긴 자리에서 작은 위성 방울이 하나 생겨 조금 늦게 떨어집니다.
- 끊긴 뒤 움직임은 물리식(초속도 + 중력)을 1/30초마다 샘플한 `ease: "none"` 트윈입니다. 여러 속성이 한 식에서 나와 어긋나지 않고 결정적입니다.
- **매달림(`hold`)**: 늘어난 뒤 장면 끝까지 천천히 15% 더 늘어나고 방울이 0.5초 주기로 가로세로 출렁입니다.

## 쓰는 법
```js
import { textToPath, textDripClips, boxDripClips, dripClips } from "./draw.mjs";
// 아이콘·박스: 모서리 둥근 부분을 피해 x를 고름. count개 중 fall개가 끊겨 떨어짐
add(...boxDripClips({ box: { x: 340, y: 520, width: 400, height: 400, radius: 96 }, color: "#15125C", startSec: 0.55, endSec: 3.4, count: 2, fall: 1 }).clips);
// 글자: 패스에서 기준선까지 내려오는 획 자리를 찾아 드립을 붙임(사람이 재지 않음). 글자 패스 Shape(<id>_text)도 같이 돌려줌
const glyph = textToPath(font, "MELT", { fontSize: 300, align: "center" });
add(...textDripClips({ glyph, centerX: 540, centerY: 720, color: "#FF3D6E", startSec: 3.4, endSec: 7.4, count: 6, fall: 1 }).clips);
// 하나만 직접
add(...dripClips({ x: 500, y: 920, color: "#15125C", startSec: 0.5, endSec: 3, width: 26, length: 560, end: "fall" }));
```
- 반환 배열 순서가 아래 → 위입니다. 클립마다 트랙 하나(렌더 하니스는 tracks 앞쪽이 위).
- 글자 드립은 `Text` 대신 글자 패스 Shape(`<id>_text`)를 씁니다. 드립 자리가 패스 기준이라 Text 렌더와 1–2px 어긋날 수 있기 때문입니다. `text: false`면 드립만 줍니다.
- `fall`은 가장 긴 드립부터 고릅니다. 한 화면에 1–2개만 떨어뜨리고 나머지는 매달아 둡니다.

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 줄기 폭 `width` | 아이콘 폭의 6–7% · 글자 획 굵기 × 0.5 | 얇으면 실처럼, 두꺼우면 덩어리처럼 |
| 목 폭 `neck` | 아이콘 width × 4 · 글자 획 굵기 이하 | 획보다 넓으면 기준선에 가는 턱이 보임 |
| 줄기 길이 | 아이콘 높이 × 1.4 · 글자 높이 × 0.3–1.6 | 다 같으면 커튼처럼 보임. 시드로 섞임 |
| 시작 간격 | 0–0.7초 | 동시에 시작하면 기계적 |
| 늘어남 `stretch` | 0.8–1.0초 | 0.5초 아래면 물, 1.5초 위면 꿀 |
| 굵은 글꼴 | 800 이상 | 가는 글꼴은 목이 획 밖으로 넘침 |

## 사운드
끊겨 떨어질 때 작은 "똑" 하나(방울이 화면을 벗어나거나 바닥에 닿는 시각). 매달린 드립은 소리 없음.

## 알려진 함정
- 대상과 **색이 같아야** 합니다. 그라데이션·외곽선·그림자 있는 대상은 이음매가 보입니다(단색 도형·글자에만).
- 둥근 모서리 위에 드립을 두면 목 윗변이 곡선 밖으로 삐져나옵니다. `boxDripClips`는 `radius`를 받아 피합니다(직접 `dripClips`를 쓸 때도 x를 모서리 반지름 + 목 폭/2 안쪽에).
- 대상이 크게 움직이는(팝 1→1.2, 흔들림) 동안에는 붙이지 않습니다. 드립은 대상과 따로 움직여 떨어져 보입니다. 대상이 자리잡은 뒤 0.1초 이상 지나서 시작합니다.
- 떨어지는 드립은 아래 문구를 지나갑니다. 문구 위에 드립 트랙을 두면 글자를 가리니, 문구가 드립 경로 아래에 있으면 `fall`을 그 열에서 빼거나 문구 트랙을 위로.
- 앱 불러오기: Shape `path`·`rounded`·`circle`과 gsapTimeline(scaleX·scaleY·y·opacity)만 쓰므로 그대로 갑니다.
