## 의도
진행 링·타임코드 같은 HUD 언어를 전환으로 키운 것입니다. 링마다 방향이 반대라 돌아가는 느낌이 강하고, 열리는 중심이 다음 장면의 주인공(제품) 자리라 시선이 그리로 갑니다. 템포를 늦추면 고급스러운 아이리스가 되어 느린 템포의 시그니처 한 곳으로도 씁니다.

## 동작 핵심
- 링 `rings`개(기본 6). 링 k의 바깥 반지름 = (k+1) × (origin에서 가장 먼 모서리 / rings), `innerRadius` = k/(k+1). 가운데 링은 부채꼴입니다. 1px 겹쳐 틈을 막습니다.
- 덮기: 짝수 링은 `endAngle 0 → 360`(시계방향), 홀수 링은 `startAngle 360 → 0`(반시계). 바깥 링이 먼저 출발하고 모두 컷 1프레임 전에 다 찹니다.
- 링이 차는 동안 각도 ∓40° → 0으로 같이 돌아 속도감을 줍니다.
- 열기: 짝수 링은 `startAngle 0 → 360`, 홀수 링은 `endAngle 360 → 0`. 안쪽 링부터 열려 origin에서 다음 장면이 먼저 보입니다. `easeOutQuad`(끝이 너무 느리면 가는 조각이 남아 튐).

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| origin | 화면 가운데 (1080×1920 기준 좌표) | 다음 장면 주인공 자리 |
| rings | 6 | 4는 굵고 차분, 8은 잘고 빠름 |
| grow / shrink | 0.4초 / 0.42초 | `intensity.durScale`(slow 1.6 → 약 1.3초) |
| colors | accent · text · background | 3색을 링마다 번갈아 |

## 사운드
덮을 때 상승하는 라이저 짧게, 꽉 찬 순간 딸깍(시계), 열릴 때 공기 빠지는 스윕.

## 알려진 함정
- 링 각도를 `paint`로 움직이므로 엔진 3.0.25 미만, 앱 불러오기에서는 꽉 찬 원으로 보입니다. 앱으로 넘길 광고는 구워 넣습니다.
- origin이 화면 가장자리면 바깥 링이 화면 밖에서 돌아 덮는 데 시간이 걸려 보입니다. 가장자리 20% 안쪽에 둡니다.
- 같은 광고에서 cover-flood와 연달아 쓰지 않습니다(둘 다 원형 덮기).
