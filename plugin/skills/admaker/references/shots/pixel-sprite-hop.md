## 의도
픽셀 레트로 방향의 훅. 캐릭터 하나가 "게임이 시작되는" 느낌으로 화면에 들어와 브랜드를 꺼내 보여 줍니다. 귀여움보다 **박에 딱 맞는 칸 단위 움직임**이 핵심입니다.

## 동작 핵심
- 스프라이트는 `templates/pixel-sprite.mjs`로 찍습니다(걷기 4칸, 점프 1칸, 대기 2칸). PNG는 1배, 엔진에서 정수배로 키웁니다.
- 걷기: 이미지 클립 `spriteSheet { cols: 4, fps: 12 }` + 위치 keyframes `x`를 `steps(n)`로. 발 프레임과 이동 단계가 같은 박자가 되게 n = 이동 시간(초) × 12.
- 점프: 다른 클립(점프 칸)으로 교체하고 `y` keyframes 3–4개를 `steps(6)`로(오름 → 정점 → 내려옴). 정점이 박에 걸리게.
- 블록 히트: 정점 박에 블록 `y` −16px(도트 2칸) 튕김, 블록 위로 로고·문구가 `steps(4)`로 솟고 코인·별 스프라이트가 흩어짐.
- 바닥: 바닥 줄·구름은 같은 격자의 도트 PNG, 소재 위 하단 1/3에만.

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 도트 크기 | 1080 폭에서 8–10px, 모든 도트 소재 같은 배율 | 소재마다 다르면 싸 보임 |
| 걷기 fps | 12 (느린 대기 6–8) | 이동 steps와 같은 박자 |
| 이동 steps | 이동 시간 × 12 | 너무 크면 부드러워져 도트답지 않음 |
| 점프 높이 | 캐릭터 키의 1–1.5배 | 정점은 박 위 |
| 팔레트 | 8–16색, 브랜드 색 포함 | 그라데이션 금지, 2–3단 램프 |

## 사운드
걷는 칸마다 아주 작은 틱(8비트), 점프 "뿅", 블록 히트 "띵" + 코인 소리. 효과음은 `ai.sfx.generate`("8-bit jump", "retro coin").

## 알려진 함정
- `pixelated`를 빼면 키운 도트가 번집니다. 프레임 캡처로 가장자리 중간색이 없는지 봅니다.
- 시트가 있으면 crop이 안 먹습니다. 애니메이션마다 시트를 따로 만듭니다.
- 회전·3D 기울이기는 도트를 깨뜨립니다(90° 단위 뒤집기만).
- `easeOutBounce` 대신 키프레임 + `steps`로 튕깁니다.

## 참조 구현
```jsonc
{ "type": "Image", "src": "hero-walk.png",
  "style": { "pixelated": true, "spriteSheet": { "cols": 4, "fps": 12 } },
  "transform": { "x": -120, "y": 1240, "width": 160, "height": 200 },
  "animations": [{ "type": "keyframes",
    "options": { "duration": 1000000, "easing": "steps(12)" },
    "params": { "0%": { "x": 0 }, "100%": { "x": 480 } } }] }
```
