## 의도
CTA 버튼(배경 + 글자 + 아이콘), 가격표(숫자 + 단위 + 취소선 가격), 기능 칩 3개, 사진 조각 + 테이프처럼 **함께 움직여야 하는 것**을 따로따로 움직이면 이음새가 보입니다. 덩어리째 등장시키고, 정착한 뒤에만 조각별 반응을 줍니다.

## 동작 핵심
- 멤버 클립에 같은 `groupId`, 프로젝트 `groups`에 `{ id, name, angle: 0 }`.
- 덩어리 등장: 멤버마다 **같은 값**의 애니메이션에 `options.origin: "group"`. 예) scale 0.6→1 + rotate −8°→0 (`easeOutBack`) + y 120→0. 그룹 중심으로 돌고 커져서 한 판처럼 보입니다.
- 정착 후 0.1–0.2초 뒤 조각별 반응: 아이콘 팝, 가격 숫자 굴러감(countUp), 버튼 반짝 한 번.
- 사진 조각 콜라주면 조각 그룹을 박마다 하나씩 탁탁 붙이고(각 0.25초), 마지막 그룹이 시그니처.

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 등장 | 0.45–0.6초 `easeOutBack`(1.4) | 길면 둔함 |
| 회전 | ±6–10° → 0 | 크면 글자 안 읽힘 |
| 조각 반응 시작 | 정착 + 0.1–0.2초 | 동시면 덩어리 느낌이 없음 |
| 멤버 수 | 2–6 | 중첩 그룹 없음 |

## 사운드
덩어리 착지 "탁" 하나, 조각 반응마다 작은 팅.

## 알려진 함정
- 멤버마다 값이 다르면 `origin: "group"`이어도 따로 노는 것처럼 보입니다. 등장 애니메이션은 복사해 똑같이.
- 오디오·잠긴 클립은 그룹에 못 넣습니다.
- 앱으로 가져오면 그룹과 origin이 남으니, 사용자가 덩어리째 옮길 수 있습니다(SKILL.md 그룹 절).

## 참조 구현
```jsonc
"groups": { "g_cta": { "id": "g_cta", "name": "CTA 버튼", "angle": 0 } },
// g_cta 멤버(버튼 배경 Shape, 글자 Text, 화살표 Shape) 모두에 같은 animations
"groupId": "g_cta",
"animations": [{ "type": "keyframes", "options": { "duration": 520000, "easing": "easeOutBack", "origin": "group" },
  "params": { "0%": { "scale": 0.6, "angle": -8, "y": 120 }, "100%": { "scale": 1, "angle": 0, "y": 0 } } }]
```
