## 의도
"모양이 모여 체계가 된다"를 보여 주는 샷입니다. 디자인 시스템, 브랜드 리뉴얼, 패턴·굿즈 광고의 상승부에 씁니다. 2D 격자를 위에서 본 3D와 매치 컷으로 이어 평면 → 입체 전환을 한 번에 보여 줍니다.

## 동작 핵심
- 배치: 시드 RNG로 칸마다 종류·회전(0/90/180/270)·색(브랜드 4색)을 정하고 2D·3D가 같은 배열을 씁니다.
- 반원 = `pie` 칸 상자 `startAngle: rot, endAngle: rot + 180`. 사분원 = 칸 **두 배** 상자, 중심을 칸 모서리에(회전에 따라 모서리와 각도를 바꿈: 0° 왼쪽 위 90→180, 90° 오른쪽 위 180→270, 180° 오른쪽 아래 270→360, 270° 왼쪽 아래 0→90).
- 입장: 칸마다 `scale` 0 → 1, `angle` −90 → 0, `back.out(1.7)` 0.4초, 시작 = (열 + 행) × 2프레임.
- 박마다: 정해진 칸만 `angle` +90(`back.inOut(1.7)` 0.32초, 가운데 `blur` 3). 사분원은 돌리면 모서리 기준이라 칸을 벗어나므로 `paint` `fillColor`로 색만 바꿈.
- 격자선(1.5px, 25%)은 `wipe`로 그려지고 네 모서리에 십자.
- 3D: 같은 칸 배열을 `depth-blocks` 씬에 넘김(`frameCols = 화면 폭 / 칸 px`). 첫 프레임은 바로 위 시점이라 2D와 같은 모습, 0.1–1.1초에 고도 90° → 33°로 눕고 0.25–1.3초에 뒤 줄부터 솟음. 2D에서 쌓인 회전·색은 최종 상태로 넘김.
- 공: `ball: { col, row, t0, beat, height }`가 가운데 높은 블록 위에서 박마다 튐(닿을 때 찌그러짐 2프레임). 끝 0.3초에 카메라가 공으로 다가가고 같은 색 원이 화면을 덮어 다음 장면으로.

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 격자 | 8×4, 칸 180px (1920 폭) | 칸 140 아래면 도형이 장식처럼 보임 |
| 뒤집히는 칸 | 박마다 25% | 50% 넘으면 어수선 |
| 3D 고도 | 33° | 25° 아래면 블록이 겹쳐 안 읽힘 |
| 공 높이 | 1.3 칸 | 화면 위로 나가지 않는지 스틸로 확인 |

## 사운드
조각 입장에 짧은 틱 묶음, 박마다 킥, 3D로 넘어갈 때 whoosh, 공이 닿을 때마다 낮은 톡.

## 알려진 함정
- 3D 씬은 앱 불러오기에서 빠집니다(three 커스텀 씬). 영상으로 미리 렌더합니다.
- 공유 렌더러에서 `shadowMap`을 켜므로 같은 시간에 다른 three 클립이 있으면 그쪽도 그림자 설정이 바뀝니다.
