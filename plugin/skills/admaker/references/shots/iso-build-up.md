## 의도
도시, 매장 지도, 서비스 구성도, 상품 상자 진열처럼 "여러 요소를 한눈에" 보여 줄 때 씁니다. 원근이 없는 2:1 아이소메트릭이라 정보 그림처럼 깔끔하고, 블록이 하나씩 솟는 리듬이 모션의 재미입니다.

## 고르는 법
| | 평면형 `iso-city-flat` | 입체형 `iso-city-3d` |
|---|---|---|
| 그리는 법 | 상자 하나 = 윗면·왼쪽·오른쪽 3색 다각형 SVG (창문 포함) | three 정사영 카메라, 실제 박스 + 조명 + 가짜 접촉 그림자 |
| 움직임 | 아래부터 솟음(`wipe` up) + 착지 눌림 | 솟음(scale.y `back.out`) + **카메라가 천천히 돌아** 옆면이 바뀜 |
| 앱 불러오기 | 그대로 감 (SVG → PNG) | 빠짐 → 3D 클립만 영상으로 미리 렌더해 Video로 |
| 고칠 때 | 상자 배치·색만 JSON에서 | 씬 코드 |
| 고르는 기준 | 기본. 앱에서 고칠 광고, 플랫 일러스트 톤 | 입체감이 주인공일 때, 카메라 회전으로 "3D"를 보여 줘야 할 때 |

두 형식은 `boxes` 배치가 같아서(`{ x, y, h, c }`) 같은 도시를 둘 다로 만들 수 있습니다.

## 동작 핵심
- 그리는 순서는 뒤 → 앞(x + y 작은 것부터). 평면형은 그 순서대로 zIndex가 올라가고, 입체형은 깊이 버퍼가 처리합니다.
- 등장도 같은 순서, 상자마다 0.07초. 바닥판이 먼저 커지며 깔림(0.35–0.4초).
- 평면형: 마스크라 상자 클립의 시작 = 솟는 시각. 솟는 동안 y +18px → 0, 다 솟으면 scaleY 0.96으로 눌렸다 `back.out(3)`.
- 입체형: 방위 45° · 고도 35.26°(진짜 아이소메트릭)에서 시작해, 다 솟은 뒤 2.2초 동안 `orbit`도만큼 돎. 톤매핑은 `NeutralToneMapping`(ACES는 파스텔을 바래게 함).

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 격자 | 4×4, 상자 14개 | 20개 넘으면 평면형 zIndex(20–48)가 모자라고 등장이 길어짐 |
| 칸 반폭 `tile` (평면) | 90–100px | 도시 폭 = 8 × tile. 화면 폭의 75% 이하 |
| 높이 `h` | 1–3.5칸 | 높이 차가 있어야 실루엣이 생김. 가장 높은 것 하나를 가운데 뒤쪽에 |
| stagger / rise | 0.07초 / 0.32초(평면)·0.45초(입체) | 박에 맞추려면 stagger = 박 / 4–8 |
| 색 | 4색 팔레트, 면마다 3단 음영 | 소재가 밝으면 채도를 조금 올림 |
| orbit (입체) | 18–40° | 40° 넘으면 아이소메트릭 느낌이 사라짐 |

## 사운드
상자가 솟을 때마다 아주 짧은 tick(블록 쌓기), 마지막 상자에 조금 큰 thunk.

## 알려진 함정
- 상자 순서를 섞으면 앞 상자 위에 뒤 상자가 그려집니다(평면형). `x + y` 순으로 정렬합니다(참조 구현이 함).
- 평면형 상자는 다른 상자와 화면 상자가 겹칩니다. 투명 SVG라 괜찮지만, 상자 클립에 필터나 그림자를 걸면 겹친 칸이 어두워집니다.
- 입체형에서 `renderer.shadowMap`을 켜면 같은 광고의 다른 3D 클립에도 걸립니다. 접촉 그림자는 바닥에 붙인 반투명 사각형으로 흉내 냅니다(three.md §4).

## 참조 구현
- 평면: `templates/shots/iso-city-flat.mjs`. `props`: `{ at, dur, cx, cy, tile, boxes: [{ x, y, h, c, w?, d? }], ground?, stagger?, rise?, palette?: [[윗면, 왼쪽, 오른쪽], …], windows? }`. `isoPoint`, `isoBoxSvg`를 export하므로 화살표·핀 같은 다른 아이소 그림에도 씁니다.
- 입체: `templates/shots/iso-city-3d.mjs` + `templates/scenes/iso-city.js`를 프로젝트 `scenes/`로 복사. `props`: 위와 같은 `boxes` + `{ box?, ground?, orbit?, zoom?, stagger?, rise? }`.
