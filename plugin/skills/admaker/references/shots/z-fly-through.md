에너지: 중고
길이: 2–3초
검증: 엔진 3.0.19 렌더 하니스 (층 3개, z +1300 / 1.2초)
엔진: 클립 `transform3d { z, perspective }` + keyframes `z`(애니메이션 값은 transform3d 위에 더해짐), opacity

## 의도
3D 공간 방향의 시그니처. 엔진에 카메라가 없으니, **모든 층에 같은 z 이동량**을 더해 카메라가 앞으로 가는 것처럼 보이게 합니다. z는 화면 중심(소실점) 기준으로 크기·위치를 같이 바꿔 줍니다.

## 동작 핵심
- 층 3–4개: 앞 층(문구) z 0, 중간(사진 카드) z −600, 먼 층(다음 장면 소재) z −1400. perspective는 모두 같게(1000–1400).
- 모든 층에 같은 구간 같은 이징으로 `z` +1200~+1500을 더합니다(`easeInOutQuart` 또는 `expo.inOut`).
- 앞 층은 z가 perspective의 0.8배를 넘기 전에 opacity 0으로(카메라를 "통과"). 엔진은 z를 원근 거리의 90%까지로 자릅니다.
- 층마다 x·y를 소실점에서 조금씩 비켜 두면(±200–400px) 지나갈 때 옆으로 스쳐 속도감이 납니다.
- 마지막 층은 z 0에 도착해 그대로 다음 장면의 바닥이 됩니다.

## 파라미터 표
| 항목 | 값 | 조절 감각 |
|---|---|---|
| 층 간격 | 500–800 | 좁으면 겹쳐 보임, 넓으면 빈 화면 |
| 총 이동 | 1200–1500 / 2–2.5초 | 빠르면 멀미, 느리면 슬라이드쇼 |
| perspective | 1000–1400, 모든 층 같게 | 다르면 소실점이 어긋남 |
| 앞 층 퇴장 | z > 0.8 × perspective 전에 opacity 0 | 늦으면 거대한 글자가 화면을 덮음 |
| 먼 층 밝기 | 앞보다 어둡게(대기 원근) | 깊이감 |

## 사운드
길게 빨려 드는 whoosh, 층을 지날 때마다 작은 휙, 도착에 낮은 쿵.

## 알려진 함정
- 레이어 순서는 z가 아니라 트랙 순서입니다. 먼 층 트랙을 아래에 둡니다.
- 소재 해상도는 최종 크기의 1.5–2배(다가오며 커짐).
- 글자 층은 정면(rotate 0)으로 두고 기울이지 않습니다. 지나갈 때 읽을 필요는 없지만, 처음 0.4초는 읽혀야 합니다.

## 참조 구현
```jsonc
// 문구 층(앞) — 다른 층도 같은 duration·easing으로 z +1300
{ "type": "Text", "text": "더 깊이", "transform3d": { "z": 0, "perspective": 1200 },
  "animations": [{ "type": "keyframes", "options": { "duration": 2200000, "easing": "easeInOutQuart" },
    "params": { "0%": { "z": 0, "opacity": 1 }, "55%": { "opacity": 1 }, "70%": { "opacity": 0 }, "100%": { "z": 1300, "opacity": 0 } } }] },
// 먼 층(다음 장면 소재)
{ "type": "Image", "src": "scene2.jpg", "transform3d": { "z": -1300, "perspective": 1200 },
  "animations": [{ "type": "keyframes", "options": { "duration": 2200000, "easing": "easeInOutQuart" },
    "params": { "0%": { "z": 0 }, "100%": { "z": 1300 } } }] }
```
