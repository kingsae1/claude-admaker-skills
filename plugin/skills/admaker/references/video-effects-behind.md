# 영상 이펙트: 인물 뒤 공간 (7종)

인물(또는 제품) 누끼를 맨 위에 두고, 그 **뒤**에 그래픽 공간을 깝니다. 순서는 항상 `배경 → 효과 → 누끼`이고, 함수에 `subject`를 넘기면 누끼 클립까지 배열 끝에 넣어 줍니다. 카탈로그는 `video-effects.md`.

```js
import * as fx from "./effects.mjs";
const subject = { src: cutoutDataUrl, box: { x: 190, y: 860, width: 700, height: 1060 } }; // removeBackground 결과
clips.push(fx.scene("bg", { type: "Image", src: backgroundUrl }, 0, 3, { x: 0, y: 0, width: 1080, height: 1920 }));
clips.push(...fx.giantType({ from: 0, to: 3, subject, text: "SALE" }));
```

공통

- **누끼가 없으면** 효과는 인물 앞에 깔리는 버전이 됩니다(`subject` 생략 → 효과만). 이때는 글자·숫자를 화면 위 1/3에 두고 얼굴을 가리지 않게 합니다.
- 배경은 인물 없는 사진(`separateLayers` 뒤 레이어)이 가장 좋고, 없으면 원본 사진을 그대로 깔아도 됩니다. 누끼가 원본의 인물 자리를 정확히 덮어야 하니 **같은 박스**에 둡니다.
- 효과 색은 브랜드 accent 하나 + 흰색. 배경이 밝으면 `color`를 브랜드 진한 색으로 바꿉니다.
- 영상 인물은 그린스크린이면 `chroma_key`로 누끼 영상을 만들어 `subject.src`에 영상 대신 넣을 수 없으니(함수는 Image로 만듦), 누끼 Video 클립을 직접 만들어 배열 끝에 둡니다: `fx.scene("subject", { type: "Video", src }, from, to, box)`.

## 1. 시계 다이얼 `clockDial`

마감 임박, 오픈 시간, "24시간", 타임랩스. 문자판(눈금 60개)이 돌며 열리고 분침이 `turns`바퀴, 시침이 그 1/12 돎.

| 값 | 기본 | 감각 |
|---|---|---|
| `center`, `radius` | 화면 위 42%, 화면 폭 46% | 얼굴 뒤에 문자판 가운데가 오게. 머리가 문자판 아래쪽 1/3에 걸리면 안정적 |
| `turns` | 3 | 2–4. 많으면 어지러움 |
| `accent` | #FF4D4D | 분침만 강조색 |

함정: 문자판과 바늘은 같은 박스(정사각)여야 가운데로 돕니다. 박스를 따로 바꾸지 않습니다.

## 2. 거대 글자 `giantType`

한 단어 훅("SALE", "NEW", "오픈"). 화면 폭 2배 박스에 글자 크기 = 화면 폭 42%, 들어올 때 1.35배·블러 16에서 0.5초에 정착, 이후 `drift`(px)만큼 옆으로 흐름.

- 4자 이하가 좋습니다. 한글 2–3자는 `size: W * 0.55`.
- `y`는 머리 위쪽이 글자 아래 1/3을 가리게(인물 뒤에 있다는 게 보여야 함).
- 확인: 머리가 글자 일부를 가리는지. 안 가리면 인물 앞에 있는 것처럼 보입니다.

## 3. 게시물 벽 `postWall`

입소문, 후기 많음, "SNS에서 난리". SVG 게시물 카드 격자(3열, 열마다 반 칸씩 엇갈림)를 `rotateX` 14°로 눕혀 `speed` px/초로 올림 + 가장자리 어둡게.

- 카드 그림은 자리표시(색 블록·하트)입니다. 실제 후기 이미지를 쓰려면 사용자 자료에 있는 것만 Image 클립으로 격자 위에 얹습니다(후기를 지어내지 않음, `ideas.md`).
- 배경 어둡게 + 카드 밝게라 인물 누끼 테두리가 잘 보입니다.

## 4. 궤도 링 `orbitRing`

혜택 칩 3–5개("무료배송", "1+1", "★4.9")가 몸을 감싸고 돎. 타원 뒤 반은 누끼 **아래**, 앞 반은 누끼 **위**에 그리고, 칩도 앞/뒤 두 벌을 opacity로 바꿔 몸 뒤로 지나가는 것처럼 보입니다.

| 값 | 기본 | 감각 |
|---|---|---|
| `center` | 화면 55% | 허리·가슴 높이. 얼굴 높이에 두면 칩이 얼굴을 가림 |
| `rx`, `ry` | 폭 44%, 폭 10% | ry/rx 0.2–0.3이 자연스러운 원근 |
| `turns` | 1.2 | 3초에 1–1.5바퀴 |
| `tilt` | −8° | 0이면 밋밋, ±15° 넘으면 기울어 보임 |

확인: 칩이 몸 뒤로 지나갈 때 실제로 가려지는지(스틸 두 장: 앞·뒤 반). 칩 글자는 6자 이하.

## 5. 숫자 카운트 `countUpBehind`

판매량·가입자·할인율. 인물 뒤 큰 숫자가 `countUp`(0 → value, `countDur` 1.6초, easeOutExpo)으로 오르고 끝에 1.08배 펀치. 위에 작은 라벨.

- 글자 안 **첫 숫자만** 셉니다(`prefix`·`suffix`는 그대로). "최대 70% 할인"이면 `prefix: "최대 "`, `value: 70`, `suffix: "%"`.
- 숫자는 사용자 자료에 있는 값만 씁니다.
- 7자("12,000+") 넘으면 `size`를 줄입니다(기본 화면 폭 24%).

## 6. 차트 상승 `chartRise`

성장·매출·만족도. 막대가 `stagger` 0.12초 간격으로 아래에서 솟고(높이·위치 keyframes), 마지막 막대가 선 뒤 꼭대기를 잇는 화살표가 `strokeDraw`로 그려집니다.

- `values`는 0–1 비율. 실제 수치가 없으면 "성장" 느낌만 주는 장식이므로 축·숫자 라벨을 달지 않습니다.
- 막대가 인물 양옆에 보이게 `area`를 화면 폭 가득 둡니다.

## 7. 무한 터널 `infiniteTunnel`

몰입, "빠져드는 맛", 게임·테크. 둥근 사각 링 `count`개가 `period`초마다 0.04배 → 3.2배로 **지수 확대**(원근처럼)하며 비틀리고, 끝에서 투명해졌다 작게 다시 시작합니다.

- 어두운 배경에서 씁니다. 링 색은 2–3색 순환.
- 링이 많을수록 무겁습니다(9개, 정지점은 링마다 수십 개). 15초 넘게 깔면 `count` 6.
- 확인: 링이 튀지 않고 이어지는지(다시 작아지는 순간은 투명해야 함).

## MCP로 직접

모두 엔진 기본 클립이라 `add_clip`으로도 넣을 수 있지만 클립 수가 많아(궤도 링 ~20, 터널 9) 스킬에서 ProjectJSON으로 만든 뒤 가져오는 쪽이 빠릅니다. 누끼만 앱에서 만들고(`ai.image.removeBackground`, 크레딧 확인), 결과 이미지 URL을 받아 `subject.src`에 넣습니다.
