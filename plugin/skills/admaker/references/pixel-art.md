# 픽셀 아트(도트) 모션그래픽

작은 도트 그림을 코드로 찍고, 엔진에서 키워서 계단식으로 움직입니다. 생성 모델에 "pixel art"를 그리게 하면 격자가 어긋나고 색이 번지니, 캐릭터·아이콘·소품은 직접 찍습니다. 사진이나 영상 바닥은 그대로 두고 `pixelateFilter`로 질감만 맞춥니다.

## 1. 엔진 기능 (엔진 3.0.19+, 앱은 엔진 버전을 올린 뒤)

| 하고 싶은 것 | 쓰는 것 |
|---|---|
| 16–64px 그림을 크게 키워도 각지게 | 이미지·영상 `style.pixelated: true` (nearest 샘플링) |
| 걷기·깜빡임 같은 프레임 애니메이션 | 이미지 `style.spriteSheet: { cols, rows?, count?, fps?, loop? }` (플립북) |
| 칸 단위로 끊기는 이동·크기 변화 | 애니메이션 `easing: "steps(n)"` (프리셋 `steps(4)`·`steps(8)`·`steps(12)`, 모션 토큰 `pixel`) |
| 사진·영상을 도트 질감으로 | 효과 `pixelateFilter { size }`, 전환 `pixelize` |
| 반짝임·지글거림 | 라인 보일(`lineBoil`)도 계단식으로 바뀜 |

- `spriteSheet`는 시트를 같은 크기 칸으로 나눠 왼→오, 위→아래 순서로 `fps`칸/초 재생합니다. `fps` 기본 8, `loop` 기본 true(false면 마지막 칸에서 멈춤). 클립 `width/height`는 **한 칸** 비율로 줍니다.
- 시트가 있으면 클립 crop은 적용되지 않습니다. 시트 하나에 애니메이션 하나를 둡니다(엔진 JSON에서만 `from`으로 시작 칸을 줄 수 있고, 앱 저장 형식은 `from`을 남기지 않음).
- 앱 MCP: `update_clip { clipId, patch: { style: { pixelated: true, spriteSheet: { cols: 4, fps: 12 } }, width: 256, height: 256 } }`. 끄려면 `spriteSheet: null`. 속성 패널은 이미지·영상의 "픽셀 아트" 섹션(선명한 픽셀, 스프라이트 시트)입니다.

## 2. 스프라이트 만들기 — `templates/pixel-sprite.mjs`

```json
{
  "palette": { ".": null, "k": "#18142A", "r": "#DC4650", "s": "#F0BE96", "b": "#506EB4" },
  "frames": {
    "walk": [["..kkk..", ".krrrk.", ".kssk..", "..kbk..", ".k.k..."], ["..kkk..", ".krrrk.", ".kssk..", "..kbk..", "..kk..."]],
    "idle": [["..kkk..", ".krrrk.", ".kssk..", "..kbk..", ".k..k.."]]
  }
}
```

`node <스킬>/templates/pixel-sprite.mjs hero.json out/hero` → `out/hero.png`(전체 시트), 애니메이션마다 `out/hero-walk.png`, `out/hero.json`(칸 크기, 애니메이션별 `spriteSheet` 값). PNG는 1배로 저장하고 엔진에서 `pixelated`로 키웁니다(`--scale`은 미리보기용).

규칙
- **격자 하나를 정합니다.** 캔버스 1080이면 도트 1개 = 8px(135칸) 또는 10px처럼, 모든 도트 소재의 확대 배율을 같은 정수로 맞춥니다. 소재마다 배율이 다르면 도트 크기가 섞여 싸 보입니다.
- **팔레트는 8–16색**, 소재 전체가 같은 팔레트를 씁니다. 그라데이션 대신 2–3단 색 램프(어두운 쪽은 색상을 살짝 차갑게)와 체커 디더를 씁니다.
- **외곽선 1px**은 가장 어두운 색 하나로. 안티에일리어싱 픽셀을 넣지 않습니다.
- **프레임 수는 적게**: 대기 2–3, 걷기 4, 점프·공격 4–6. 12fps가 기본, 느린 루프는 6–8fps.
- 글자는 도트 폰트(앱 폰트 검색 `search_fonts "pixel"` 또는 `"bitmap"`)를 쓰고, 크기는 격자 배율의 정수배로 둡니다. 직접 찍은 글자 PNG도 됩니다.

## 3. 움직임

- 위치·크기 키프레임은 `steps(n)` 이징으로 칸 단위로 끊습니다. n은 "이동 거리 ÷ 도트 크기"보다 작게(예: 320px를 도트 8px로 → `steps(8)`~`steps(40)`, 한 번에 여러 칸 점프가 오히려 도트답습니다).
- 걷기는 플립북(`spriteSheet`) + 위치 `steps` 이동을 같이 겁니다. 발 프레임과 이동 단계가 같은 박자(같은 fps)가 되게 맞춥니다.
- 튕김은 `easeOutBounce` 대신 키프레임 3–4개를 `steps`로(떨어짐 → 찌그러짐 → 살짝 튀어오름 → 정지).
- 장면 전환은 `pixelize` 전환이나 큰 블록이 칸 단위로 덮이는 마스크가 어울립니다. 부드러운 fade·블러 전환은 피합니다.
- 회전·3D 기울이기는 도트가 깨지니 쓰지 않습니다(90° 단위 반전·뒤집기는 괜찮음).

## 4. 검수

- 확대한 소재에 번진 가장자리(중간색 픽셀)가 없는지 프레임을 캡처해 확인합니다(`pixelated` 빠짐).
- 도트 크기가 소재마다 같은지, 팔레트 밖 색이 없는지.
- 플립북이 클립 길이 안에서 자연스럽게 반복되는지(`loop: false`면 마지막 칸 유지 시간을 확인).
