# 광고 문구: 훅, 온램프, 카피

광고에 들어가는 글자(훅, 자막, 타이틀, 가격·혜택 문구, CTA)를 쓰는 방법입니다. `director.md` §3 메시지 설계를 구체화하고, 검수는 `aesthetic-rules.md` C 규칙으로 합니다.
(출처: coreyhaines31/marketingskills의 ad-creative·copywriting·offers 문서를 한국 광고와 admaker 구조에 맞게 다시 쓴 것. `ATTRIBUTION.md` 참고)

## 1. 훅은 세 칸이다

첫 3초의 훅은 한 문장이 아니라 동시에 일어나는 세 가지입니다.

| 칸 | admaker에서 맡는 것 | 할 일 |
|---|---|---|
| 화면 동작 | 바닥 소재(사용자 영상·이미지)와 그 위의 첫 모션 | 엄지를 멈춘다 |
| 내레이션 첫 마디 | 내레이션(없으면 이 칸은 비움) | 궁금증을 연다 |
| 자막·타이틀 | 모션 그래픽 글자 | 무음 시청자에게 주장을 박는다 |

**세 칸은 서로 반복하지 않습니다.** 내레이션이 "하루 10분이면 끝나요"라고 말하는데 자막도 "하루 10분이면 끝"이면 두 칸을 낭비한 것입니다. 화면은 실제 장면을 보여 주고, 내레이션은 문장을 말하고, 자막은 다른 각도(숫자, 대상, 결과)를 붙입니다. 내레이션이 없는 광고는 화면 + 자막 두 칸이고, 자막이 화면을 그대로 설명하지 않게 합니다.
트리트먼트의 훅 표(`templates/TREATMENT.md`)에 세 칸을 모두 적습니다. 한 칸만 채운 훅은 3분의 1짜리 훅입니다.

## 2. 훅을 만드는 순서

`대상 → 동기 → 형식 → 훅(세 칸)` 순서로 씁니다. 위 단계를 건너뛰면 남의 광고처럼 읽힙니다.

1. **대상**: 이 광고가 말을 거는 사람 한 부류. "20–30대 여성"이 아니라 "퇴근하고 저녁 차릴 힘이 없는 1인 가구"처럼 상황을 공유하는 부류.
2. **동기**: 그 사람을 움직이는 고통·욕구·망설임 하나. 사용자가 준 리뷰·문의·댓글이 있으면 그 사람들의 말을 그대로 씁니다. 마케팅 말투로 바꾸면 힘이 빠집니다.
3. **형식**: 소재가 무엇을 보여 줄 수 있는지가 형식을 정합니다(제품 클로즈업, 사용 장면, 비포/애프터, 화면 녹화, 언박싱). 문장을 쓰기 전에 고릅니다.
4. **훅**: 이 대상 × 동기 × 형식에 맞춰 세 칸을 씁니다.

후보를 낼 때는 한 칸의 표현만 바꾼 변형 열 개보다, 대상·동기가 다른 후보 세 개가 낫습니다.

## 3. 오프닝 메뉴

훅 후보 3개는 서로 다른 칸에서 고릅니다. 한두 개에만 몰리지 않게 돌려 씁니다.

| 오프닝 | 모양 (예시는 구조 설명용, 실제 문구 아님) | 주의 |
|---|---|---|
| 호기심 | 명사를 숨김: "오후 3시에 졸린 진짜 이유" | 광고 안에서 답을 줘야 합니다. 안 주면 낚시 |
| 대담한 주장 | 구체적이고 확인 가능한 말: "아침 루틴을 이걸로 바꿨어요" | 화면이나 다음 비트에 근거 |
| 고백 | "지금까지 ○○을 잘못 하고 있었어요" | 생활감 있는 디테일 없으면 가짜처럼 읽힘 |
| 비포/애프터 | 두 상태를 첫 비트에 | 변화가 화면에서 정직해야 함(§7) |
| 공감·POV | 아주 구체적인 상황: "퇴근길 지하철, 저녁 메뉴 고민 중" | 구체성이 전부. 일반적인 POV는 안 보임 |
| 질문 | 고객이 실제로 검색창에 치는 질문 그대로 | 고객 말투 그대로 |
| 증거 먼저 | 결과 화면, 숫자, 제품이 일하는 장면부터 | 증거가 스스로 자랑할 때 가장 강함 |
| 카운트다운 | 타이머·챌린지로 끝의 보상을 약속 | 보상이 실제로 있어야 함 |
| 선택 | 두 선택지를 내밀기: "A냐 B냐" | 둘 다 시청자가 실제로 고민하는 것 |
| 예전 vs 지금 | "예전엔 ○○, 요즘은 △△. 뭐가 나을까?" | 답에서 편을 들어야 함 |
| 우리 vs 그들 | "대부분은 X를 해요. 잘하는 사람은 Y를 해요" | "대부분"이 실제 행동이어야 함 |
| 통념 깨기 | "○○ 없어도 됩니다" | 반응이 강함. 경쟁사 실명은 쓰지 않음(§7) |

뒤의 다섯(선택~통념 깨기)은 모두 **대비**입니다. 대비 훅은 설명형·고민형 상품에 잘 맞고, **충동구매형 상품(식품, 패션, 뷰티, 소품)은 증거 먼저나 공감·POV**로 여는 편이 낫습니다.
`director.md` §3의 "문제, 숫자, 움직임, 제품 중 하나로 바로 시작"은 이 메뉴의 증거 먼저·비포/애프터·공감에 해당합니다.

## 4. 온램프: 3–15초는 훅을 이어 간다

훅 다음 구간(15초 광고의 ②주인공, 30초 광고의 ②–③ 앞부분)은 **훅이 연 전제를 그대로 이어 가야** 합니다. 훅이 "졸린 진짜 이유"를 약속했으면 다음 비트는 그 이유를 설명하기 시작합니다. 갑자기 브랜드 소개나 회사 연혁으로 넘어가면 시청자가 빠집니다.
훅을 바꾸면 온램프도 같이 고칩니다. 같은 본편에 훅만 갈아 끼우면 전제가 끊깁니다.

## 5. 시청자가 어디까지 아는가

광고를 보는 사람이 이 문제·제품을 얼마나 아는지에 따라 문구의 일이 달라집니다. 브리프에서 모르면 하나를 가정하고 `TREATMENT.md`에 적습니다.

| 시청자 | 필요한 것 | 어울리는 문구 | CTA 방향 |
|---|---|---|---|
| 문제를 모름 | 자기 상황을 알아봄 | 감정 한 장면, 짧은 대화 | 더 알아보기 |
| 문제는 앎 | 빠져나갈 길이 보임 | 고통 + 결과, "아직도 ○○ 하세요?" 형 마찰 | 방법 보기 |
| 해결책은 앎 | 이 방식이 어떻게 다른지 | 전/후 상태 변화, 근거 있는 숫자 | 비교·시연 보기 |
| 제품을 앎 | 마지막 망설임 해소 | 구체적 증거, 혜택·가격 | 구매·예약·가입 |

리타깃·재방문 광고는 보통 "제품을 앎", 처음 보는 소셜 피드 광고는 "문제는 앎"이 기본값입니다.

## 6. 쓰지 않는 문구

기계가 쓴 것처럼 읽히는 문구는 광고 전체의 신뢰를 깎습니다. **금지**는 한 번도 쓰지 않고, **제한**은 한 광고에 한 번까지입니다.

| 유형 | 예 | 등급 | 고치는 법 |
|---|---|---|---|
| 아무도 안 한 말을 부정하고 뒤집기 | "단순한 ○○이 아닙니다. △△입니다", "○○? 이제 그만" | 금지 | △△와 그 근거만 말합니다 |
| 없는 것 3연발 | "복잡한 설정 없이, 기다림 없이, 걱정 없이" | 금지 | 실제로 되는 것 하나를 구체적으로 |
| 빈 수식어 | "새로운 차원의", "혁신적인", "당신의 일상을 바꿀", "특별한 경험" | 금지 | 숫자·사물·장면으로 바꿉니다 |
| 근거 없는 최상급 | "최고", "1위", "유일한", "가장 빠른" | 금지(근거가 있으면 출처와 함께) | §7 |
| 거창한 시작·끝 | "지금, ○○의 시작", "이제 경험해 보세요" | 제한 | 엔드카드는 구체적 행동 동사로 |
| 셋 묶음 | "쉽고, 빠르고, 똑똑하게" | 제한 | 셋이 실제로 셋일 때만 |
| 느낌표·물음표 남발 | 한 화면에 두 개 이상 | 제한 | 화면당 하나 |

한 화면 한 문장(C1), 3초 안에 읽히는 길이, 숫자는 아라비아 숫자는 그대로 지킵니다.

## 7. 정직한 주장, 정직한 할인

광고 문구에 들어가는 사실은 모두 사용자가 준 자료에서 나와야 합니다. **수치, 후기, 순위, 인증은 지어내지 않습니다.** 사용자가 근거를 주지 않은 주장은 빼거나 사용자에게 확인합니다.

- **최상급·비교 표현**: "최고·1위·최초·유일" 같은 말이나 타사와의 비교는 객관적 근거(조사 기관, 기간, 대상)가 있을 때만 쓰고, 근거를 화면에 작게라도 표기합니다(예: "○○리서치 2026년 3월 조사"). 경쟁사 실명은 사용자가 법무 검토를 확인하지 않으면 쓰지 않습니다.
- **비포/애프터**: 실제 같은 대상의 실제 결과만. 효과를 과장하는 합성·보정은 하지 않습니다. 식품·화장품·건강기능식품은 효능 표현 제한이 엄격하니, 효능 주장(치료, 개선, 다이어트 효과 등)이 있으면 사용자에게 심의·근거 여부를 묻습니다.
- **협찬·광고 표기**: 후기형·인플루언서형 광고는 경제적 대가가 있으면 "광고", "협찬" 같은 표시를 시청자가 알아볼 수 있게 넣습니다(첫 화면 또는 제목 근처).
- **할인·마감**: 실제 기간·수량·조건이 있을 때만 씁니다. 다시 시작되는 카운트다운, 근거 없는 "마감 임박", "선착순 ○명", 항상 주는 혜택을 "오늘만"으로 쓰는 것은 금지입니다. 기간이 있으면 날짜를 적습니다("11월 30일까지"). 가격 롤(`price-countup`)은 정가·할인가 모두 사용자 자료와 같아야 합니다.
- 규정은 바뀝니다. 위 항목은 기본 점검이고 법률 검토를 대신하지 않습니다. 업종 규제(의료, 금융, 주류, 식품)가 있는 광고는 납품할 때 사용자에게 심의 확인을 권합니다.

## 8. 문구 작업물

`TREATMENT.md`의 "문구" 절에 다음을 적습니다.

1. 시청자 단계 가정(§5) 한 줄
2. 훅 후보 3개: 오프닝 종류, 세 칸(화면·내레이션·자막), 동기의 출처(사용자 자료의 어느 문장인지)
3. 선택한 훅과 온램프 첫 문장
4. 화면별 자막·타이틀 문구 목록(초 단위), 엔드카드 메시지와 CTA
5. 근거 표: 문구에 든 숫자·주장마다 출처(사용자 자료, 날짜)
