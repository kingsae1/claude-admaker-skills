# 영상 이펙트: 화면 오버레이 (8종)

바닥 영상·사진 위에 화면 UI를 얹는 효과입니다. 인물 누끼가 필요 없어 어떤 소재에도 바로 씁니다. 카탈로그는 `video-effects.md`.

공통

- 한국어 문구는 모두 Text 클립(Noto Sans KR 700)입니다. 창·말풍선·키보드 같은 틀만 SVG로 그립니다(SVG 안 글자는 시스템 글꼴이라 한글이 깨질 수 있음).
- 창·배너 안 글자는 틀과 **같은 keyframes**를 씁니다. scale은 박스 가운데 기준이라 `windowPopup`은 자식 글자 위치를 부모 가운데 기준으로 보정합니다(`relativeScale`). 직접 만들 때도 같은 보정을 합니다.
- 얼굴·제품을 가리지 않게 화면 위 1/3이나 아래 1/4에 둡니다(샘플은 보여 주려고 가운데에 둠).
- 문구는 사용자 자료에 있는 것만. 댓글·알림·후기를 지어내 사실처럼 보이게 하지 않습니다. 연출용 가상 문구면 "예시" 성격이 분명한 말(제품 장점 요약)로 씁니다.

## 22. 창 팝업 `windowPopup`

혜택 나열, "알림이 쏟아지는", 앱·SaaS. 창마다 `{ title, body, box }`, `stagger` 0.35초 간격으로 0.6배에서 `easeOutBack`으로 열립니다. `dark: true`면 어두운 창.

- 창 3–4개, 뒤 창일수록 오른쪽 아래로 120px씩 비켜 계단식.
- 본문 `size` 기본 54, 한 줄 12자 이하.

## 23. 댓글 폭포 `commentWaterfall`

입소문, 라이브 커머스. 댓글 `{ name, text }`가 `every`(0.45초)마다 화면 아래 86%에서 나와 `speed`(420px/초)로 올라가며 위에서 사라집니다(아바타 원 색 순환).

- 폭 `width` 화면의 72%, 왼쪽 정렬(`x` 60). 오른쪽은 제품·인물 자리.
- 댓글 5–8개를 돌려 씁니다. 한 댓글 18자 이하.

## 24. 손글씨 낙서 `handDoodle`

강조, 리뷰, 친근한 톤. `marks = [{ kind, target, at, color? }]` — kind: underline·doubleUnderline·strike·circle·box·arrow·check·cross·bracket(`draw.mjs` annotationPath) + star. 0.55초 `strokeDraw`로 그려진 뒤 `lineBoil`(10fps, variants 3)로 손떨림이 남습니다.

- 장면당 2개까지, 대상이 자리잡은 뒤 0.2–0.4초에(`drawing.md` 손그림 강조 규칙).
- MCP `draw_annotation`과 같은 계산이라 앱에서 하나만 넣을 때는 그 도구가 빠릅니다.

## 25. 라이브 커서 `liveCursor`

협업 툴, "직접 골라 보세요", 화면 녹화풍. `path = [[t, x, y], …]`로 커서 + 이름표가 `easeInOutCubic`으로 이동하고 `clicks = [t]`마다 커서가 0.82배로 눌리며 물결 원이 퍼집니다.

- 지점 3–5개, 지점 사이 0.6–0.9초. 클릭은 버튼·제품 위에서.
- 커서 여러 명(공동 편집)은 함수를 이름·색을 바꿔 여러 번 부릅니다.

## 26. 예측 키보드 `predictiveKeyboard`

검색·메시지 연출, "○○ 하면 생각나는". 아래에서 키보드가 올라오고, 입력창에 `words`가 한 단어씩 쳐지며(계단 wipe) 그 단어 동안 위 추천 칸 3개(`suggestions[i]`)가 보이다 첫 칸이 파랗게 눌립니다. 글자마다 아무 키 하나가 눌려 반짝입니다.

- 쳐지는 효과는 Text 클립 하나에 `wipe` + `easing: steps(글자 수)`입니다. 한글은 글자 폭이 거의 같아 1.0 × fontSize로 계산합니다(단어 사이 0.35칸).
- 키보드 자판은 QWERTY 라틴 글자(SVG)입니다. 두벌식 한글 자판이 필요하면 키 라벨을 Text로 바꿉니다.
- `cps` 기본 8자/초. 3단어 안팎이 3초에 맞습니다.

## 27. 터미널 타이핑 `terminalTyping`

개발자·테크·"한 줄이면 끝". 어두운 창에 `$` 프롬프트 + 명령어가 Space Mono로 한 글자씩(`cps` 18, 계단 wipe) 쳐지고 결과 줄이 0.12초 간격으로 찍히며, 블록 커서가 깜빡입니다.

- 고정폭 글꼴이라 계단 wipe가 글자 경계에 정확히 맞습니다(글자 폭 = 0.6 × fontSize). 다른 글꼴로 바꾸면 반쯤 잘린 글자가 보입니다.
- 명령어는 영문·숫자. 한글 결과 줄은 따로 Noto Sans KR Text로 얹습니다.
- 줄 수 × 1.5 × `size`가 창 높이 안에 들어가게.

## 28. 알림 폭탄 `notificationBomb`

인기 폭발, 주문 쇄도, 이벤트 알림. `every`(0.22초)마다 배너가 위에서 `easeOutBack`으로 떨어지고, 앞 배너들은 한 칸씩 아래로 밀리며 조금씩 작아집니다(`max` 7칸 넘으면 사라짐). 최신 알림이 맨 위.

- 배너 `{ app, title, body, color }`. title 14자, body 18자 이하.
- 3초에 8–12개. 끝에 휴대폰 진동처럼 흔들려면 바닥 클립에 `shake`.

## 29. 뉴스 속보 `breakingNews`

화제성, 신메뉴·오픈 소식, 패러디 톤. 빨간 "속보" 띠 → 흰 헤드라인 바 → 검은 티커 바가 차례로 wipe로 밀려 들어오고, 티커 글자가 `speed`(220px/초)로 흐르며, 왼쪽 위 "● LIVE"가 깜빡입니다.

- `headline` 16자 이하, `ticker`는 " · "로 이은 문장 3–4개를 한 줄로.
- 실제 방송사 로고·이름을 흉내 내지 않습니다.

## MCP로 직접

- 손글씨 낙서 = `draw_annotation`. 나머지는 클립 수가 많아(댓글 폭포 3초 ≈ 20클립) 스킬에서 만들어 가져옵니다.
- 이미 만든 광고에 붙일 때는 효과 클립의 from·to를 그 구간으로 두고, 바닥은 앱에 있는 것을 그대로 씁니다(효과 함수는 바닥을 만들지 않음).
