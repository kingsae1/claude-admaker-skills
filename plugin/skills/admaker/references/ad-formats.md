# 광고 규격

매체가 정한 규격이 이 표보다 우선합니다. 납품 직전 각 매체의 최신 가이드를 다시 확인합니다(규격은 자주 바뀝니다).

## 길이별 구조

| 길이 | 용도 | 구조 | 메시지 |
|---|---|---|---|
| 6초 | 범퍼, 리마인드 | 제품+브랜드 동시 → 엔드카드 | 1개, 문장 1개 |
| 15초 | 소셜 피드, 프리롤 | 훅 → 주인공 → 혜택 1–2개 → 엔드카드 | 1개 |
| 30초 | 프리롤, TV | 훅 → 주인공 → 혜택 3–4개 → 엔드카드 | 1개 + 근거 |
| 60초 | 브랜드, 설명 | 스토리 호 + 혜택 + 엔드카드 | 1개 + 스토리 |

## 비율과 해상도

| 비율 | 해상도 | 매체 예 |
|---|---|---|
| 16:9 | 1920×1080 | 유튜브, 웹, TV |
| 9:16 | 1080×1920 | 릴스, 쇼츠, 틱톡, 스토리 |
| 1:1 | 1080×1080 | 피드 |
| 4:5 | 1080×1350 | 피드(세로) |

기본 fps는 30입니다.

## 세이프존 (세로 9:16 기준)

- 상단 약 14%(프로필·제목), 하단 약 20%(캡션·CTA 버튼), 오른쪽 약 12%(좋아요·공유 버튼)에는 글자·로고·CTA를 두지 않습니다.
- 가로 16:9는 사방 5% 안쪽을 타이틀 세이프로 둡니다.

## 리프레임 (한 광고를 여러 비율로)

1. 레이아웃을 비율별 앵커(상단 정렬, 중앙, 하단 정렬)로 정의하고 좌표를 직접 쓰지 않습니다.
2. 타임라인은 공유하고 레이아웃만 비율별로 바꿉니다. `build-project.mjs --size 1080x1920`.
3. 세로에서는 글자를 한 단계 키우고, 한 화면의 요소 수를 줄입니다.
4. 비율마다 컨택트 시트를 따로 보고 세이프존을 확인합니다.

## 오디오

- 소셜: −14 LUFS 통합, true peak −1 dBTP.
- 방송: 매체 규격(예: −24 LKFS)을 따릅니다.
- 소셜 광고는 무음 재생이 많으므로 자막을 번인합니다.
